1. 問題の設定

事例の概要

内国法人（当社）は、シンガポールに100%子会社を有する。同子会社はペーパーカンパニー（特定外国関係会社）に該当し、CFC税制に基づき各事業年度の所得を合算すべきであったが、失念していた。今年の税務調査により合算漏れが発覚した。

事業年度基準所得金額現地法人税額状況
×1年▲100万円10万円合算漏れ
×2年300万円14万円合算漏れ
前提条件
(1) 持株割合100%（請求権等勘案合算割合 = 100%）
(2) シンガポール子会社以外に国外所得なし
(3) 子会社配当調整・部分対象外国関係会社特有の調整なし
(4) ×1年以前に繰越欠損金なし
(5) 所得は基準所得金額に読替可能な簡略設例

分析すべき核心論点

  1. 各年度の適用対象金額と修正申告の要否

2.2 適用対象金額の計算式

適用対象金額は、基準所得金額に繰越欠損金額及び納付法人所得税の額に関する調整を加えた金額とされています。 財務省「令和6年度税制改正の解説」（措法66条の6②四、措令39条の15⑤）
適用対象金額 = 基準所得金額 − 繰越欠損金 − 納付法人所得税 + 還付法人所得税 − 控除対象配当等

NTA別表十七（三の二）（令和7年4月1日以後終了事業年度分）の欄構成: 欄9（基準所得金額）、欄8（繰越欠損金の当期控除額）、欄24（納付法人所得税）、欄25（還付法人所得税）がこの構造を反映している。

3. ×1年の分析 ── 欠損年度の処理

3.1 適用対象金額

項目金額根拠
基準所得金額▲100万円措令39条の15①②
適用対象金額0円基準所得金額 < 0 のため
課税対象金額0円0 × 100% = 0
益金算入額0円措法66条の6①不適用

結論：適用対象金額がゼロであり、修正申告は不要。ただし▲100万円はCFC繰越欠損金として翌期以降に繰り越される（措令39条の15⑤）。

3.2 措法66条の7のゲート構造 ── 10万円が救済されない理由

内国法人が前条第1項（第66条の6第1項）の規定の適用を受ける場合には、当該内国法人に係る外国関係会社……の所得に対して課される外国法人税の額……のうち、当該内国法人の課税対象金額に対応するもの……は、……控除対象外国法人税の額とみなす。 租税特別措置法 第66条の7 第1項（要旨）

この「前条第1項の規定の適用を受ける場合には」が制度全体のゲートキーパーとして機能する。×1年は適用対象金額がゼロであり、66条の6第1項による益金算入が生じないため、66条の7第1項の条件節を充足しない。ゲートが閉鎖され、後続の全てが遮断される。

ステップ×1年の状態結果
① 適用対象金額 = 0基準所得金額 < 0課税対象金額 = 0
② 措法66条の6①益金算入なし「適用を受ける」事実なし
③ 措法66条の7①条件節を充足しないゲート閉鎖
④ みなし納付発動しない控除対象外国法人税 = 0
⑤ 法69条対象税額なし10万円は救済されない
×1年のシンガポール法人税10万円は、日本の税制上一切の救済を受けることができない。
みなし納付のゲートが閉鎖されているため、この10万円は「控除対象外国法人税の額」として認識されない。法69条の世界に入ることがなく、控除限度超過額としての繰越（法69条②）も、控除余裕額による吸収（法69条③）の対象にもならない。

4. ×2年の分析 ── 適用対象金額とみなし外税

4.1 適用対象金額の計算

項目金額根拠別表十七（三の二）欄
基準所得金額300万円措令39条の15①②欄9
繰越欠損金の当期控除額▲100万円措令39条の15⑤欄8
納付法人所得税の額▲14万円措令39条の15⑤欄24
適用対象金額186万円欄26
適用対象金額 = 300万円 − 100万円 − 14万円 = 186万円

持株割合100%であるから、課税対象金額 = 186万円 × 100% = 186万円。この金額が親法人の益金に算入される（措法66条の6①）。

4.2 みなし控除対象外国法人税額の按分計算 ── 条文の正確な読み方

ここが本分析の最重要論点である。措令39条の18第3項は、みなし控除対象外国法人税額の按分計算について、次の構造を定める。

外国法人税の額に、当該課税対象年度に係る適用対象金額又は調整適用対象金額のうちに、内国法人に係る課税対象金額の占める割合を乗じて計算した金額とする。 租税特別措置法施行令 第39条の18 第3項（要旨）
按分の分母は「基準所得金額」（300万円）ではない。
しばしば「14万円 × 186/300 ≒ 8.7万円」という計算が示されるが、これは現行条文の構造に合わない。現行措令39条の18③の分母は「調整適用対象金額」であり、外国関係会社の所得（300万円）や基準所得金額ではない。

NTA別表十七（三の五）（令和7年4月1日以後終了事業年度分）の欄構成が、この条文構造を明確に反映している。

別表十七（三の五）の欄内容本件の値
欄(5) / 課税対象金額別表十七（三の二）「28」から転記186万円
欄(6) / 外国法人税額現地法人税額14万円
欄(8) / 適用対象金額別表十七（三の二）「26」から転記186万円
欄(9)・(10) / 配当調整子会社配当等・控除対象配当等（課税標準に含まれるもの）0円
欄(11) / 調整適用対象金額= (8) + (9) + (10)186万円
欄(13) / 按分割合= 課税対象金額(5) ÷ 調整適用対象金額(11)100%
欄(14) / みなし控除対象外国法人税額= 外国法人税額(6) × 按分割合(13)14万円
みなし控除対象外国法人税額 = 外国法人税額 × (課税対象金額 ÷ 調整適用対象金額) = 14万円 × (186万円 ÷ 186万円) = 14万円 × 100% = 14万円
なぜ按分比率が1になるか
100%保有・特殊な配当調整なしという前提の下では、課税対象金額 = 適用対象金額 = 調整適用対象金額となる。いずれも186万円であるため、比率は1になり、外国法人税額14万円が全額みなし控除対象外国法人税額となる。持株割合が100%未満であれば、課税対象金額が適用対象金額を下回り、按分比率が1未満となって部分的な認識に留まる。

4.3 みなし外税額の益金算入

措法66条の7第2項に基づき、みなし控除対象外国法人税額14万円は親法人の益金にも算入される。したがって、×2年の親法人への影響は次のとおりである。

項目金額根拠
CFC合算による益金算入額186万円措法66条の6①
みなし外税の益金算入額14万円措法66条の7② / 法41条
合計益金算入額200万円
外国税額控除額（税額控除）▲14万円法69条①（限度額の範囲内）

5. 国外所得金額の算出方法

5.1 法人税法施行令の二重リミッター

国外所得金額は、施行令141条の2第1項に基づき「国外源泉所得に係る所得の金額の合計額（当該合計額が零を下回る場合には、零）」と定義される。さらに施行令142条3項が90%キャップをかける。

調整国外所得金額 = min( max( 国外所得金額, 0 ), 全世界所得金額 × 90% )
リミッター条件根拠
ゼロフロア国外所得金額 < 0 → 0として扱う施行令141条の2①
90%キャップ所得金額の90%を超過 → 90%に制限施行令142条③

5.2 CFC合算所得と国外所得金額の関係 ── 措令39条の18⑬の重要性

第1項の規定により内国法人が納付するものとみなされる金額は、法人税法施行令第142条第3項本文に規定する調整国外所得金額に含まれるものとする。 租税特別措置法施行令 第39条の18 第13項（要旨）

この規定は、みなし控除対象外国法人税額14万円が、控除限度額計算の分子側にも反映されることを明示する。したがって、×2年の国外所得側は、CFC合算額186万円だけでなく、みなし外税14万円も加えた金額で考える必要がある。

×2年の国外所得側の出発点: = CFC課税対象金額 186万円 + みなし外税益金算入 14万円 = 200万円

×1年0円（合算なし）0円0円ゼロフロア適用の余地もなし

5.4 控除限度額の計算

控除限度額 = 法人税額 × (調整国外所得金額 ÷ 所得金額)

親法人に他の所得・損失がなく、全世界所得 ≒ 200万円と仮定した場合:

項目金額備考
所得金額200万円CFC合算186万 + みなし外税益金14万
国外所得金額200万円
調整国外所得金額180万円min(200万, 200万×90%) = 180万
法人税額（23.2%想定）46.4万円
控除限度額41.8万円46.4万 × 180/200
みなし外税14万円控除限度額41.8万円の範囲内 → 全額控除可能
親法人の所得次第で結論が変わり得る
上記はCFC案件が唯一の所得源という仮定による。親法人に国内損失がある場合、所得金額が圧縮され、調整国外所得金額も90%キャップにより更に縮小するため、14万円全額が当期に控除できない可能性がある。その場合、控除限度超過額として法69条②により3年間繰り越される。最終控除額は、親法人の当該年度の所得金額・法人税額を確認しなければ確定できない。

6. 外国税額控除の繰越の可否

6.1 繰越制度の概要

制度内容期間根拠
控除限度超過額の繰越控除対象外国法人税 > 控除限度額 の場合3年法69条②
控除余裕額の繰越控除限度額 > 控除対象外国法人税 の場合3年法69条③

6.2 ×1年の10万円が繰越不可能な理由

  1. 適用対象金額 = 0 → 課税対象金額 = 0
  2. 措法66条の6①の「適用を受ける」事実がない
  3. 措法66条の7①のゲートが閉鎖 → みなし納付が発動しない
  4. 10万円は「控除対象外国法人税の額」として認識されない
  5. 法69条②③の繰越制度に入る前提を欠く

6.3 直接外国税額控除との構造的対比

CFC税制（みなし納付）直接外国税額控除（支店等）
欠損年度の外国税控除対象外国法人税にならない → 繰越不可控除限度超過額として3年間繰越可能
制度の入口措法66条の7①のゲート（条件節）法69条①に直接アクセス
根本的違い「みなし」効果 → ゲートが閉じれば何も発生しない「実際の納付」→ 納付した事実で控除対象外国法人税が成立

7.2 当初申告要件の廃止

令和2年度改正により外国税額控除の当初申告要件は廃止された。修正申告においてCFC合算と外国税額控除を同時に適用できる。法69条25項は、確定申告書・修正申告書又は更正請求書に所定の明細書を添付し、課税証明書類等を保存している場合に適用するとしている。

7.3 必要な別表と添付書類

書類内容
別表十七（三の二）適用対象金額の計算明細（基準所得金額300万、繰越欠損金100万、法人所得税14万）
別表十七（三の五）みなし控除対象外国法人税額の計算（調整適用対象金額186万、按分100%、みなし外税14万）
別表六（二の二）→ 別表六（二）外国税額控除の控除限度額計算・最終控除額
別表四CFC合算所得186万円の益金加算 + みなし外税益金14万円
添付書類シンガポール子会社の納税証明書、財務諸表、持株関係を証する書類

7.4 加算税

項目税率備考
過少申告加算税10%（50万円超部分15%）増差税額（FTC控除後）が計算基礎

みなし外税14万円を控除することで増差税額が圧縮され、加算税の額も軽減される。CFC本体だけを認識して外税控除を取りこぼすと、実質的な追徴額が不必要に大きくなる。

8. 構造的課題と総括

8.1 CFC税制における外国税額控除の構造的問題

  1. 欠損年度の外国税の死蔵：措法66条の7①のゲート構造により、欠損年度に現地で納付した法人税は日本側で一切の救済を受けられない。繰越制度にもアクセスできない。
  2. 直接FTCとの非対称性：自社支店の直接FTCなら欠損年度でも控除限度超過額として3年間繰り越せるが、CFCみなし納付にはこの経路がない。
  3. 按分計算の誤解されやすさ：措令39条の18③の分母は「調整適用対象金額」であるが、基準所得金額や外国課税標準で按分するという誤った説明が広く流布している。NTA別表十七（三の五）の欄構成を確認することで正しい計算構造を把握できる。

8.2 実務上の示唆

  • CFC合算は毎期漏れなく行うことが極めて重要。欠損年度の外国税は事後的救済が不可能。
  • 修正申告では、CFC合算と外国税額控除を必ず同時に主張すべき（当初申告要件は廃止済み）。
  • みなし外税の計算では、別表十七（三の五）の欄構成に従い、調整適用対象金額ベースの按分を行う。
  • 措令39条の18⑬により、みなし外税額は控除限度額計算の分子（調整国外所得金額）にも反映する。分子を課税対象金額だけで止めると不利な処理となる。
  • 最終控除額は常に親法人側の限度額（所得金額・法人税額）で絞られるため、親法人の国内損益を確認しなければ確定できない。

本分析の要約

×1年（欠損年度）

  • 適用対象金額 = 0 → 修正申告不要
  • 繰越欠損金100万円が発生
  • 現地法人税10万円: ゲート閉鎖により永久に死蔵

×2年（黒字年度）

  • 適用対象金額 = 300 − 100 − 14 = 186万円
  • みなし外税 = 14万円 × 186/186 = 14万円（全額）
  • 国外所得金額: 186万 + 14万 = 200万円
  • 修正申告で200万円益金算入 + 14万円税額控除
  • （最終控除額は親法人の限度額次第）

外国法人税合計24万円のうち、日本側で救済される金額: 14万円（救済率 58.3%）
未救済: ×1年の10万円（ゲート閉鎖による構造的限界）
