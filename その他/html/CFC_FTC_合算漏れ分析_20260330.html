1. 事実関係と前提

事業年度基準所得金額現地法人税額状況
×1年▲100万円10万円合算漏れ
×2年300万円14万円合算漏れ
前提：持株割合100%。シンガポール子会社はペーパーカンパニー（特定外国関係会社）。配当調整・部分合算の論点なし。これ以外に国外所得なし。

2. 制度の全体像 ── 条文はどう連鎖するか

CFC合算課税から外国税額控除に至るまで、以下の条文が順番に作用する。一つでも要件を欠けば、後続の条文は発動しない。

#条文何をするか
①措令39条の15①②⑤基準所得金額を算定し、繰越欠損金・法人所得税を控除して適用対象金額を確定
②措法66条の6①課税対象金額を親法人の益金に算入
③措法66条の7①外国法人税を親法人の控除対象外国法人税とみなす（ゲート条項）
④措令39条の18③みなし控除対象外国法人税額の按分計算
⑤措令39条の18⑫⑬益金算入額・みなし外税を調整国外所得金額に算入
⑥法69条①控除限度額の計算と外国税額控除の実行
⑦施行令141条の2・142条国外所得金額の定義、ゼロフロア、90%キャップ

3. ×1年：なぜ10万円は救済されないのか

×1年は基準所得金額が▲100万円であるため、適用対象金額はゼロとなり、CFC合算による益金算入は生じない。問題は、シンガポールで実際に納付した10万円が日本側で外国税額控除の対象になるかである。

答えはならない。その根拠は、措法66条の7第1項の条文構造にある。

租税特別措置法 第66条の7 第1項（e-Gov法令API取得・抜粋）
前条第一項各号に掲げる内国法人（……を除く。）が、前条第一項、第六項又は第八項の規定の適用を受ける場合には、当該内国法人に係る外国関係会社の所得に対して課される外国法人税の額のうち、当該外国関係会社の課税対象金額に対応するものとして政令で定めるところにより計算した金額……は、……当該内国法人が納付する控除対象外国法人税の額とみなして、同法第六十九条……の規定を適用する。
※ 括弧書き・読替規定を省略して骨格のみ抽出

この条文の発動要件は「前条第一項……の規定の適用を受ける場合には」である。×1年は適用対象金額がゼロであるため、「前条第一項」（措法66条の6第1項）による益金算入が生じない。益金算入が生じなければ「適用を受ける」事実がなく、66条の7第1項の条件節を充足しない。

ステップ×1年の状態結果
基準所得金額▲100万円適用対象金額 = 0
措法66条の6①益金算入額 = 0「適用を受ける」事実なし
措法66条の7①条件節「適用を受ける場合には」充足せず → ゲート閉鎖
みなし納付発動しない控除対象外国法人税 = 0
×1年のシンガポール法人税10万円救済されない
構造的帰結：ゲートが閉じた時点で、10万円は「控除対象外国法人税の額」として日本の税制上認識されない。法69条の世界に入ることがなく、控除限度超過額としての繰越（法69条②）も不可能である。これはCFC税制の構造的限界であり、事後的な救済手段は存在しない。

ただし、×1年の欠損▲100万円は、CFC繰越欠損金として×2年の適用対象金額の計算において控除される（措令39条の15⑤）。

4. ×2年：適用対象金額186万円の導出

×2年は基準所得金額が300万円で正であるため、CFC合算の対象となる。適用対象金額は、措令39条の15第5項に基づき次のとおり計算される。

租税特別措置法施行令 第39条の15 第5項（e-Gov・要旨）
適用対象金額は、外国関係会社の各事業年度の基準所得金額から次に掲げる金額の合計額を控除した残額とする。
一　当該各事業年度開始の日前七年以内に開始した事業年度において生じた欠損金額の合計額に相当する金額
二　当該外国関係会社が当該各事業年度において納付をすることとなる法人所得税の額

NTA別表十七（三の二）の欄構成もこの条文を反映している。

項目金額条文根拠別表欄
基準所得金額300万円措令39条の15①②欄9
繰越欠損金（×1年分）▲100万円措令39条の15⑤一欄8
納付法人所得税▲14万円措令39条の15⑤二欄24
適用対象金額186万円欄26
適用対象金額 = 300万 − 100万 − 14万 = 186万円

持株割合100%なので、課税対象金額 = 186万円 × 100% = 186万円。これが措法66条の6第1項に基づき親法人の益金に算入される。

5. ×2年：みなし外税は8.7万円ではなく14万円

ここが本分析の最重要論点である。しばしば「14万円 × 186/300 ≒ 8.7万円」という按分計算が示されるが、これは現行条文の構造に合わない。

5.1 条文の正確な読み方

租税特別措置法施行令 第39条の18 第3項（e-Gov法令API取得・抜粋）
法第六十六条の七第一項に規定する課税対象金額に対応するものとして政令で定めるところにより計算した金額は、外国関係会社につきその課税対象年度の所得に対して課される外国法人税の額に、当該課税対象年度に係る適用対象金額（第三十九条の十五第一項第四号に掲げる金額……又は……控除対象配当等の額……がある場合には、これらの金額を加算した金額。……「調整適用対象金額」という。）のうちに法第六十六条の七第一項に規定する内国法人に係る課税対象金額の占める割合を乗じて計算した金額とする。
※ 企業集団等所得課税規定に関する括弧書きを省略

この条文を算式に分解すると：

みなし控除対象外国法人税額 = 外国法人税額 × ( 課税対象金額 ÷ 調整適用対象金額 )
分母は「基準所得金額」（300万円）ではない。
条文の文言上、按分の分母は「調整適用対象金額」であり、外国関係会社の課税標準や基準所得金額ではない。「14万円 × 186/300 ≒ 8.7万円」という計算は、分母に300万円（基準所得金額）を代入しているが、現行措令39条の18③はそのような構造になっていない。

5.2 「調整適用対象金額」とは何か

措令39条の18③は、調整適用対象金額を次のように定義する：

調整適用対象金額 = 適用対象金額 + 子会社配当等（外国法人税の課税標準に含まれるもの）+ 控除対象配当等（同上）

本件では子会社配当等・控除対象配当等はいずれもゼロであるため：

調整適用対象金額 = 186万円 + 0 + 0 = 186万円

5.3 NTA別表十七（三の五）による確認

NTA「外国関係会社の課税対象金額等に係る控除対象外国法人税額の計算に関する明細書」（別表十七（三の五）、令和7年4月1日以後終了事業年度分）の欄構成は、この条文構造を明確に反映している。

欄内容本件の値
(5)課税対象金額〔別表十七(三の二)「28」〕186万円
(6)外国法人税額14万円
(8)適用対象金額〔別表十七(三の二)「26」〕186万円
(9)子会社配当等（課税標準に含まれるもの）0円
(10)控除対象配当等（課税標準に含まれるもの）0円
(11)調整適用対象金額 = (8)+(9)+(10)186万円
(13)按分割合 = (5)÷(11)100%
(14)みなし控除対象外国法人税額 = (6)×(13)14万円
みなし控除対象外国法人税額 = 14万円 × (186万 ÷ 186万) = 14万円 × 100% = 14万円
なぜ比率が1になるか：100%保有・配当調整なしの前提では、課税対象金額 = 適用対象金額 = 調整適用対象金額（いずれも186万円）。したがって按分比率は1になり、外国法人税額14万円が全額みなし控除対象外国法人税額となる。持株割合が100%未満であれば比率は1を下回る。

5.4 みなし外税の益金算入

租税特別措置法 第66条の7 第2項（e-Gov・要旨）
前条第一項各号に掲げる内国法人が……前項の規定により法人税法第六十九条第一項から第三項まで……の規定の適用を受けるときは、前項の規定により控除対象外国法人税の額とみなされた金額は、当該内国法人の政令で定める事業年度の所得の金額の計算上、益金の額に算入する。

したがって、×2年のみなし外税14万円は、親法人の益金にも算入される。合計の益金算入額は 186万円 + 14万円 = 200万円。

6. 国外所得金額の算出 ── ゼロフロアと90%キャップ

6.1 国外所得金額のゼロフロア

法人税法施行令 第141条の2 第1項（e-Gov法令API取得）
法第六十九条第一項に規定する政令で定める金額は、内国法人の各事業年度の次に掲げる国外源泉所得に係る所得の金額の合計額（当該合計額が零を下回る場合には、零）とする。

国外所得金額は、マイナスでもゼロに切り上げられる。これは申告様式上の作法ではなく、施行令の明文規定である。

6.2 CFC合算がある場合の国外所得金額 ── 措令39条の18⑫⑬

CFC事案では、一般の国外所得金額に加え、CFC固有の二つの条文が分子側に影響する。

租税特別措置法施行令 第39条の18 第12項（e-Gov・抜粋）
法第六十六条の六第一項……の規定により益金の額に算入された金額（以下この項において「益金算入額」という。）がある場合には、当該益金算入額は、……法人税法施行令第百四十二条第三項本文に規定する調整国外所得金額に含まれるものとする。
→ CFC合算額186万円が調整国外所得金額に入る根拠
租税特別措置法施行令 第39条の18 第13項（e-Gov・抜粋）
第八項各号に掲げる外国法人税の額のうち法第六十六条の七第一項の規定により外国関係会社に係る内国法人が納付する控除対象外国法人税の額とみなされる金額は、……法人税法施行令第百四十二条第三項本文に規定する調整国外所得金額に含まれるものとする。
→ みなし外税14万円も調整国外所得金額に入る根拠

この2つの規定により、×2年の国外所得側は次のようになる。

国外所得金額 = CFC益金算入額（186万円）措令39条の18⑫ + みなし外税益金（14万円）措令39条の18⑬ = 200万円

6.3 調整国外所得金額と90%キャップ

控除限度額の分子になるのは「調整国外所得金額」であり、所得金額の90%を上限とする（施行令142条③）。

調整国外所得金額 = min( 国外所得金額, 所得金額 × 90% )

親法人にCFC以外の所得・損失がないと仮定した場合：

項目金額備考
所得金額200万円CFC益金186万 + みなし外税益金14万
国外所得金額200万円措令39条の18⑫⑬
調整国外所得金額180万円min(200万, 200万×90%)
法人税額（23.2%想定）46.4万円
控除限度額41.8万円46.4万 × 180÷200
みなし外税 14万円全額控除可能（14万 < 41.8万）
ただし最終控除額は親法人の所得次第。親法人に国内損失がある場合、所得金額が圧縮され、調整国外所得金額も90%キャップにより縮小する。14万円全額が当期に控除できない場合、残額は控除限度超過額として法69条②により3年間繰り越される。

7. 外国税額控除の繰越 ── なぜ×1年は繰り越せないか

7.1 法69条の繰越制度

制度条文繰越期間要件
控除限度超過額の繰越法69条②3年控除対象外国法人税 > 控除限度額
控除余裕額の繰越法69条③3年控除限度額 > 控除対象外国法人税

7.2 ×1年の10万円が繰越不可能な理由

いずれの繰越制度も、当該外国税が「控除対象外国法人税の額」として成立していることが前提である。×1年の10万円は、以下の条文連鎖により、この前提を欠く。

  1. 適用対象金額 = 0 → 措法66条の6①の適用がない
  2. 措法66条の7①の「適用を受ける場合には」を充足しない → みなし納付が発動しない
  3. 10万円は「控除対象外国法人税の額とみなされる金額」にならない
  4. 法69条の世界に入る前提を欠く → 控除限度超過額にも控除余裕額にもならない
  5. 繰り越す対象自体が存在しない

7.3 直接外国税額控除との対比

CFC税制（みなし納付）直接FTC（支店等）
外国税の認識措法66条の7①のゲートを通過して初めて認識納付した事実で直ちに認識
欠損年度の外国税ゲート閉鎖 → 一切認識されない控除限度超過額として3年繰越可能
根本的違い「みなし」＝法律上の擬制 → 条件不充足なら擬制なし「実際の納付」→ 無条件に認識

8. 修正申告の手続き

年度修正申告理由
×1年不要適用対象金額 = 0
×2年必要益金算入200万円 + FTC 14万円

令和2年度改正により外国税額控除の当初申告要件は廃止済み。修正申告でCFC合算と外国税額控除を同時に適用できる。

必要書類

書類内容
別表十七（三の二）適用対象金額の計算（基準所得300万、欠損100万、法人所得税14万 → 186万）
別表十七（三の五）みなし外税の計算（調整適用対象金額186万、按分100%、みなし外税14万）
別表六（二の二）→別表六（二）控除限度額の計算と外国税額控除の実行
添付書類シンガポール子会社の納税証明書、財務諸表、持株関係書類

過少申告加算税（10%/15%）と延滞税が課されるが、みなし外税14万円を控除することで増差税額が圧縮され、加算税も軽減される。CFC本体だけ認容して外税控除を取りこぼすと不必要に大きな追徴となる。

9. 総括

本分析の要約

×1年（欠損年度）

  • 適用対象金額 = 0 → 修正申告不要
  • 繰越欠損金100万円が発生
  • 現地法人税10万円：措法66条の7①のゲート閉鎖により永久に死蔵

×2年（黒字年度）

  • 適用対象金額 = 300−100−14 = 186万円
  • みなし外税 = 14万円×186/186 = 14万円（全額）
  • 国外所得金額 = 186万+14万 = 200万円
  • 修正申告で200万円益金算入 + 14万円税額控除
  • 最終控除額は親法人の控除限度額次第

外国法人税合計24万円のうち、日本側で救済可能: 14万円
未救済: ×1年の10万円（CFC税制の構造的限界）
