1. 問題の設定

事例の概要

内国法人（当社）は、シンガポールに100%子会社を有する。同子会社はペーパーカンパニー（特定外国関係会社）に該当し、本来はCFC税制（外国子会社合算税制）に基づき各事業年度の所得を合算すべきであったが、失念していた。今年実施された税務調査により合算漏れが発覚した。

事業年度基準所得金額現地法人税額合算申告
×1年▲100万円10万円漏れ
×2年300万円14万円漏れ
前提条件
(1) 持株割合100%（請求権等勘案合算割合 = 100%）
(2) シンガポール子会社以外に国外所得なし
(3) ×1年以前に繰越欠損金なし
(4) ×1年の所得▲100万円は、CFC税制上の基準所得金額として算定された値

分析すべき論点

  1. 各年度の適用対象金額と修正申告の要否
  2. 外国税額控除（みなし納付）の適用可否
  3. 国外所得金額の算出方法と控除限度額の計算
  4. ×1年の現地法人税10万円の救済可能性（繰越を含む）

2. CFC税制の適用判定と条文連鎖

2.1 ペーパーカンパニーの判定

シンガポール子会社がペーパーカンパニー（特定外国関係会社）に該当する場合、経済活動基準による適用除外の判定を経ることなく、会社単位の合算課税が適用される（措法66条の6②二）。

2.2 適用対象金額の計算構造 ── 条文の連鎖

CFC合算課税から外国税額控除に至るまでの条文は、以下の連鎖構造を形成する。

段階条文内容
①措令39条の15①②基準所得金額の算定（本邦法令基準 or 現地法令基準）
②措令39条の15⑤繰越欠損金の控除
③措法66条の6②四適用対象金額 = 基準所得金額 − 繰越欠損金 − 納付法人所得税 + 還付法人所得税 − 控除対象配当等
④措法66条の6①課税対象金額（= 適用対象金額 × 持株割合）の益金算入
⑤措法66条の7①みなし納付外国法人税額（＝外国税額控除の対象）
⑥措令39条の18①みなし納付額の按分計算
⑦法69条①外国税額控除（控除限度額の計算）
⑧法人税法施行令142条国外所得金額の算出

2.3 適用対象金額の計算式

財務省の改正解説（令和6年版）は、適用対象金額について次のように述べている。

適用対象金額は、基準所得金額に繰越欠損金額及び納付法人所得税の額に関する調整を加えた金額とされています。 財務省「令和6年度税制改正の解説」（措法66条の6②四、措令39条の15⑤）

国税庁の申告書別表十七（三の二）（令和7年4月1日以後終了事業年度分）もこの構造を反映しており、基準所得金額（欄9）の算出後に、繰越欠損金の当期控除額（欄8）、当期中に納付することとなる法人所得税の額（欄24）、当期中に還付を受けることとなる法人所得税の額（欄25）を別枠で調整する様式となっている。

適用対象金額 = 基準所得金額 − 繰越欠損金 − 納付法人所得税 + 還付法人所得税 − 控除対象配当等

3. ×1年の分析 ── 欠損年度の処理

3.1 適用対象金額の算定

項目金額根拠
基準所得金額▲100万円措令39条の15①②
適用対象金額0円基準所得金額 < 0 のため
課税対象金額0円0 × 100% = 0
CFC合算による益金算入額0円措法66条の6① 不適用

結論：適用対象金額がゼロであるため、CFC合算による益金算入は生じない。したがって×1年について修正申告は不要である。

3.2 繰越欠損金の発生

基準所得金額がマイナスとなった場合のマイナス額（100万円）は、措令39条の15⑤に基づくCFC繰越欠損金として翌事業年度以降に繰り越される。

CFC繰越欠損金の特徴
(1) 法人税法57条の国内法人の欠損金繰越制度とは別の枠組み（措令39条の15⑤）
(2) 国内法人側の確定申告における申告要件は課されない
(3) 現地法の繰越規定とも独立した日本側の独自計算
(4) 合併等による欠損金の引継ぎは認められない

3.3 措法66条の7のゲート構造 ── 10万円が救済されない理由

×1年のシンガポール法人税10万円について、外国税額控除（みなし納付）の適用を受けることができるか。結論はできない。その理由は措法66条の7第1項の条文構造にある。

内国法人が前条第1項（第66条の6第1項）の規定の適用を受ける場合には、当該内国法人に係る外国関係会社……の所得に対して課される外国法人税の額……のうち、当該内国法人の課税対象金額に対応するもの……は、……控除対象外国法人税の額とみなす。 租税特別措置法 第66条の7 第1項（要旨）

この「前条第1項の規定の適用を受ける場合には」という条件節が、制度全体のゲートキーパーとして機能する。

ステップ×1年の状態結果
① 適用対象金額0円（基準所得金額 < 0）課税対象金額 = 0
② 措法66条の6①益金算入額 = 0「適用を受ける」事実なし
③ 措法66条の7①条件節を充足しないゲート閉鎖
④ みなし納付発動しない控除対象外国法人税 = 0
⑤ 外国税額控除対象税額なし10万円は救済されない
×1年の現地法人税10万円は、日本の税制上一切の救済を受けることができない。
みなし納付のゲートが閉鎖されているため、この10万円は控除対象外国法人税として認識されず、法69条の外国税額控除の世界に入ることがない。結果として、控除限度超過額としての繰越（法69条②）も、控除余裕額による吸収（法69条③）の対象にもならない。

4. ×2年の分析 ── 黒字年度の処理

4.1 適用対象金額の計算

×2年は基準所得金額が300万円であり、×1年の繰越欠損金100万円および当期の納付法人所得税14万円を控除して適用対象金額を算定する。

項目金額根拠別表十七（三の二）欄
基準所得金額300万円措令39条の15①②欄9
繰越欠損金の当期控除額▲100万円措令39条の15⑤欄8
当期中に納付する法人所得税の額▲14万円措法66条の6②四欄24
還付法人所得税・控除対象配当等0円該当なし欄25・15
適用対象金額186万円
適用対象金額 = 300万円 − 100万円 − 14万円 = 186万円

持株割合100%であるから、課税対象金額 = 186万円 × 100% = 186万円。この金額が親法人の益金に算入される（措法66条の6①）。

4.2 みなし納付外国法人税額の按分計算

措法66条の7第1項に基づき、シンガポール子会社の外国法人税のうち課税対象金額に対応する部分が、親法人が納付する控除対象外国法人税の額とみなされる。按分計算は措令39条の18第1項による。

みなし納付外国法人税額 = 外国法人税額 × (課税対象金額 ÷ 外国法人税の課税標準)

= 14万円 × (186万円 ÷ 300万円)
= 14万円 × 0.62
= 8.68万円（≒ 8.7万円）

この8.7万円は法69条1項の外国税額控除の対象となるとともに、法人税法41条に基づき親法人の益金にも算入される。

項目金額備考
CFC合算による益金算入額186万円措法66条の6①
みなし納付FTCの益金算入額8.7万円法41条（控除を受けた外国税の益金算入）
合計益金算入額194.7万円
外国税額控除額▲8.7万円法69条①（税額控除）
×2年で救済されない外国税
シンガポール法人税14万円のうち、みなし納付として控除対象になるのは8.7万円（186/300按分）のみ。残りの5.3万円（14 − 8.7）は、繰越欠損金控除分（100万円分）と納付法人所得税控除分（14万円分）に対応する部分であり、日本側で控除されない。

4.3 控除限度額の計算

外国税額控除の控除限度額は、法69条1項に基づき次の算式で計算する。

控除限度額 = 法人税額 × (調整国外所得金額 ÷ 全世界所得金額)

本件では×2年のCFC合算所得186万円（＋みなし納付益金算入8.7万円 = 194.7万円）が唯一の国外源泉所得であるため、親法人に他の所得がなければ国外所得金額 ≒ 全世界所得金額となり、控除限度額 = 法人税額の全額となる。みなし納付8.7万円は控除限度額の範囲内に収まるため、全額控除が可能である。

5. 国外所得金額の算出方法

5.1 法人税法施行令142条の基本構造

外国税額控除の控除限度額の計算における「国外所得金額」は、法人税法施行令142条に基づき、次の二重のリミッターを経て算出される。

調整国外所得金額 = min( max( 国外所得金額, 0 ), 全世界所得金額 × 90% )
リミッター条件効果根拠
ゼロフロア国外所得金額 < 00として扱う法人税法施行令142条
90%キャップ国外所得金額 > 全世界所得 × 90%全世界所得の90%に制限法人税法施行令142条

5.2 ゼロフロアの趣旨と効果

国外所得金額がマイナスの場合にゼロとして扱うルールの実質的意味は以下のとおりである。

  • 控除限度額 = 法人税額 × (0 ÷ 全世界所得) = 0
  • 当該事業年度では外国税額控除が一切使えない
  • ただし、直接外国税額控除の場合は、控除対象外国法人税自体は存在するため、全額が控除限度超過額として法69条2項に基づき3年間繰り越せる

5.3 CFC合算所得と国外所得金額の関係

CFC合算により益金算入された金額は、国外源泉所得として国外所得金額に含まれる。本件の各年度における国外所得金額は次のとおりである。

年度CFC合算額国外所得金額ゼロフロア適用控除限度額
×1年0円（合算なし）0円─0円
×2年186万円186万円 + 8.7万円※不要法人税額の範囲内

※ みなし納付外国法人税額の益金算入分を含む

×1年の国外所得金額の取扱い
×1年はCFC合算自体が行われないため、国外所得金額は0円である（他に国外所得がない前提）。仮にCFC合算が行われる場合であっても、適用対象金額がゼロであれば国外所得金額もゼロとなり、ゼロフロアとの関係で控除限度額は0円となる。いずれのルートからも外国税額控除の余地はない。

6. 外国税額控除の繰越の可否

6.1 法69条の繰越制度の概要

制度内容繰越期間根拠
控除限度超過額の繰越控除対象外国法人税 > 控除限度額 の場合、超過額を繰越3年法69条②
控除余裕額の繰越控除限度額 > 控除対象外国法人税 の場合、余裕額を繰越3年法69条③

6.2 ×1年の10万円が繰越不可能な理由

繰越制度を利用するためには、当該外国税が「控除対象外国法人税の額」として日本の税制上認識されていることが前提となる。×1年の10万円は、以下の条文連鎖により、この前提を充足しない。

  1. 適用対象金額 = 0 → 課税対象金額 = 0（措法66条の6②四）
  2. 措法66条の6第1項の「適用を受ける」事実がない
  3. 措法66条の7第1項のゲートが閉鎖 → みなし納付が発動しない
  4. 10万円は「控除対象外国法人税の額」として認識されない
  5. 法69条の世界に入らない → 控除限度超過額にも控除余裕額にもならない
  6. ∴ 繰越す対象自体が存在しない

6.3 ×2年の控除余裕額

×2年では控除限度額（法人税額の相当部分）に対してみなし納付8.7万円のみが控除対象であるため、大幅な控除余裕額が発生する。しかし、×1年側に控除限度超過額が存在しないため、この余裕額は×1年の10万円を吸収することができない。×3年以降に別の控除限度超過額が生じた場合にのみ活用される。

6.4 直接外国税額控除との構造的対比

CFC税制（みなし納付）直接外国税額控除（支店等）
欠損年度の外国税控除対象外国法人税にならない → 繰越不可控除限度超過額として3年間繰越可能
制度の入口措法66条の7① の条件節（ゲート）法69条① に直接アクセス
ゲートの有無あり（「適用を受ける場合には」）なし（納付した事実のみで認識）
構造的非対称性
直接外国税額控除では、親法人が自ら納付した外国税は「控除対象外国法人税」として直ちに認識される。国外所得がマイナスで控除限度額が0円であっても、控除限度超過額として3年間繰り越せる。CFC税制のみなし納付にはこの救済経路がなく、ゲートが閉じた時点で外国税は日本の税制上永久に認識されなくなる。

7. 修正申告時の手続き

7.1 各年度の修正申告の要否

年度修正申告理由
×1年不要適用対象金額 = 0、益金算入なし
×2年必要186万円の益金算入 + みなし納付FTC 8.7万円

7.2 当初申告要件の廃止

令和2年度（2020年）税制改正により、外国税額控除の当初申告要件は廃止された。これにより、当初の確定申告書に外国税額控除を記載していなかった場合であっても、修正申告において外国税額控除を新たに適用することが可能となった。

実務上の意味
本件のようにCFC合算漏れが税務調査で発覚し修正申告を行う場面において、CFC合算による益金算入と外国税額控除（みなし納付）を同時に適用できる。これにより増差税額が圧縮され、過少申告加算税の計算基礎も減少する。

7.3 ×2年の修正申告で必要な手続き

手続き内容
別表十七（三の二）適用対象金額の計算明細（基準所得金額300万、繰越欠損金100万、法人所得税14万を記載）
別表六（二の二）みなし納付外国税額控除の計算（控除対象外国法人税8.7万円）
別表四CFC合算所得186万円の益金加算 + みなし納付FTC益金算入8.7万円
添付書類シンガポール子会社の納税証明書（Tax Certificate）、財務諸表、持株関係を証する書類

7.4 加算税・延滞税

CFC合算漏れに基づく修正申告について、以下のペナルティが発生する。

項目税率備考
過少申告加算税10%（50万円超部分15%）増差税額（FTC控除後）が計算基礎
延滞税年率（変動制）法定納期限の翌日から完納日まで
重加算税35%仮装隠蔽があった場合のみ（単純な合算漏れでは通常不適用）

みなし納付外国税額控除8.7万円を適用することにより、増差税額が圧縮され、過少申告加算税の額も軽減される。修正申告においてFTCを同時に主張することは、ペナルティ軽減の観点からも極めて重要である。

8. 構造的課題と総括

8.1 CFC税制における外国税額控除の構造的限界

本事例は、CFC税制と外国税額控除の交差点に存在する3つの構造的問題を浮き彫りにしている。

  1. 欠損年度の外国税の死蔵：措法66条の7第1項のゲート構造により、適用対象金額がゼロの年度に現地で納付した法人税は、日本の税制上一切の救済を受けることができない。繰越制度にもアクセスできない。
  2. 直接FTCとの非対称性：自社の支店等を通じた直接外国税額控除であれば、欠損年度でも控除限度超過額として3年間繰り越せる。CFC税制のみなし納付にはこの経路がなく、同じ「二重課税の排除」を目的としながら、結果に大きな差が生じる。
  3. 按分による部分的死蔵：黒字年度であっても、繰越欠損金控除および法人所得税控除の結果、適用対象金額が基準所得金額を下回る場合、按分計算により外国税の一部（本件では5.3万円）が控除対象から外れる。

8.2 計算フロー全体図

8.3 実務上の示唆

  • CFC合算は毎期漏れなく行うことが極めて重要。合算漏れが生じた場合、欠損年度の外国税は永久に死蔵となり、事後的な救済は不可能である。
  • 修正申告においては、CFC合算と外国税額控除を必ず同時に主張すべきである。当初申告要件は廃止されており、修正申告時の新規適用が可能。
  • 合算漏れの年度に欠損がある場合、その繰越欠損金は翌期以降の適用対象金額計算で使用できるため、黒字年度の合算額を圧縮する効果がある。

本分析の要約

×1年（欠損年度）

  • 適用対象金額 = 0 → 修正申告不要
  • 繰越欠損金100万円が発生
  • 現地法人税10万円はゲート閉鎖により永久に死蔵

×2年（黒字年度）

  • 適用対象金額 = 300−100−14 = 186万円
  • みなし納付FTC = 14×186/300 = 8.7万円
  • 修正申告で186万円益金算入 + 8.7万円税額控除
