2. 制度の全体像 ── 条文はどう連鎖するか

CFC合算課税から外国税額控除の国外所得金額に至るまで、以下の条文が順番に作用する。

#条文何をするか
①措令39条の15⑤基準所得金額から欠損金・法人所得税を控除して適用対象金額を確定
②措法66条の6①課税対象金額を親法人の益金に算入
③措法66条の7①外国法人税を親法人の控除対象外国法人税とみなす（ゲート条項）
④措令39条の18③みなし控除対象外国法人税額の按分計算
⑤措法66条の7②みなし外税額を益金算入
⑥措令39条の18⑫CFC益金算入額を調整国外所得金額に算入
⑦措令39条の18⑬みなし外税額を調整国外所得金額に算入
⑧施行令142条③調整国外所得金額に90%キャップを適用
⑨法69条①・施行令142条①控除限度額を計算

3. ×1年の処理 ── 欠損年度のゲート構造

×1年は基準所得金額が▲100であるため、適用対象金額はゼロとなり、CFC合算による益金算入は生じない。

租税特別措置法 第66条の7 第1項（抜粋）
前条第一項各号に掲げる内国法人が、前条第一項、第六項又は第八項の規定の適用を受ける場合には、当該内国法人に係る外国関係会社の所得に対して課される外国法人税の額のうち、当該外国関係会社の課税対象金額に対応するものとして政令で定めるところにより計算した金額……は、……当該内国法人が納付する控除対象外国法人税の額とみなして、同法第六十九条……の規定を適用する。

措法66条の7①の発動要件は「前条第1項の規定の適用を受ける場合には」である。×1年は適用対象金額がゼロであるため措法66条の6①による益金算入が生じず、このゲート条項を充足しない。

ステップ×1年の状態結果
基準所得金額▲100適用対象金額 = 0
措法66条の6①益金算入額 = 0「適用を受ける」事実なし
措法66条の7①ゲート条項充足せず → 閉鎖
みなし外税不発動控除対象外国法人税 = 0
×1年の欠損▲100は繰越される。CFC繰越欠損金として、×2年以降の適用対象金額の計算において控除される（措令39条の15⑤一、繰越期間7年）。

4. ×2年：適用対象金額150の導出

×2年は基準所得金額が300であるため、CFC合算の対象となる。適用対象金額は措令39条の15⑤に基づき計算される。

租税特別措置法施行令 第39条の15 第5項（要旨）
適用対象金額は、外国関係会社の各事業年度の基準所得金額から次に掲げる金額の合計額を控除した残額とする。
一　当該各事業年度開始の日前七年以内に開始した事業年度において生じた欠損金額の合計額に相当する金額
二　当該外国関係会社が当該各事業年度において納付をすることとなる法人所得税の額
項目金額条文根拠
基準所得金額300措令39条の15①②
繰越欠損金（×1年分）▲100措令39条の15⑤一
納付法人所得税▲50措令39条の15⑤二
適用対象金額150
適用対象金額 = 300 − 100 − 50 = 150

持株割合100%であるため、課税対象金額 = 150 × 100% = 150。これが措法66条の6①に基づき親法人の益金に算入される。

補足：利益250と基準所得金額300の乖離

CFCの利益（現地会計上の所得）は250であるが、基準所得金額は300と50の差がある。これは日本税法の規定に準じた計算（いわゆる「本邦法令基準」、措令39条の15①）による調整の結果であり、現地会計上は認められる費用・損金が日本税法上は認められない場合などに生じる。外国税額控除の計算には基準所得金額300ベースの適用対象金額150を使用する。

5. ×2年：みなし外税の按分計算

×2年は適用対象金額が正であるため、措法66条の7①のゲートが開き、CFCの外国法人税50が親法人のみなし控除対象外国法人税の対象となる。

5.1 条文の正確な読み方

租税特別措置法施行令 第39条の18 第3項
法第六十六条の七第一項に規定する課税対象金額に対応するものとして政令で定めるところにより計算した金額は、外国関係会社につきその課税対象年度の所得に対して課される外国法人税の額に、当該課税対象年度に係る適用対象金額（第三十九条の十五第一項第四号に掲げる金額……又は……控除対象配当等の額……がある場合には、これらの金額を加算した金額。……「調整適用対象金額」という。）のうちに法第六十六条の七第一項に規定する内国法人に係る課税対象金額の占める割合を乗じて計算した金額とする。

この条文を算式に分解すると：

みなし控除対象外国法人税額 = 外国法人税額 × ( 課税対象金額 ÷ 調整適用対象金額 )
分母は「基準所得金額300」でも「CFC利益250」でもない。
条文の文言上、按分の分母は「調整適用対象金額」（= 適用対象金額 + 子会社配当等 + 控除対象配当等）であり、CFCの課税標準でも基準所得金額でもない。「50 × 150/300 = 25」や「50 × 150/250 = 30」という計算は誤りである。

5.2 「調整適用対象金額」の算定

調整適用対象金額 = 適用対象金額 + 子会社配当等（外国法人税の課税標準に含まれるもの）+ 控除対象配当等（同上）

本件では子会社配当等・控除対象配当等はいずれもゼロであるため：

調整適用対象金額 = 150 + 0 + 0 = 150

5.3 計算結果

項目金額
外国法人税額50
課税対象金額150
調整適用対象金額150
按分割合 = 150 ÷ 150100%
みなし控除対象外国法人税額50
みなし外税 = 50 × (150 ÷ 150) = 50 × 100% = 50
なぜ比率が100%か：100%保有・配当調整なしの前提では、課税対象金額 = 適用対象金額 = 調整適用対象金額（いずれも150）。按分比率は1になり、外国法人税額50が全額みなし控除対象外国法人税額となる。持株割合が100%未満であれば課税対象金額が小さくなり、比率は1を下回る。

5.4 みなし外税の益金算入

租税特別措置法 第66条の7 第2項（要旨）
前項の規定により控除対象外国法人税の額とみなされた金額は、当該内国法人の政令で定める事業年度の所得の金額の計算上、益金の額に算入する。

みなし外税50は、親法人の×2年の益金にも算入される。合計の益金算入額は 150 + 50 = 200。

6. ×2年：国外所得金額の算出 ── 措令39条の18⑫⑬

これが本分析の核心である。CFC合算額が外国税額控除の「国外所得金額」にどう反映されるかは、一般の外国税額控除と異なる特殊な条文構造を持つ。

6.1 一般の国外所得金額の定義

法人税法施行令 第141条の2 第1項
法第六十九条第一項に規定する政令で定める金額は、内国法人の各事業年度の次に掲げる国外源泉所得に係る所得の金額の合計額（当該合計額が零を下回る場合には、零）とする。

法69条④に列挙される「国外源泉所得」とは、国外事業所等帰属所得、国外資産の運用・譲渡・保有所得、外国株式配当等である。CFC合算益金算入額はこれらの類型に直接該当しない。これは、CFC合算が「実際に国外で稼得した所得」ではなく、措法66条の6による法律上の擬制的益金算入であるためである。

問題の所在：CFC合算額が一般の国外所得金額の定義に含まれないとすると、外国税額控除の控除限度額の分子がゼロになり、みなし外税50の控除が不可能になる。これでは二重課税の排除という制度趣旨に反する。

6.2 解決：措令39条の18⑫⑬による特別算入

この問題を解決するのが、措令39条の18の第12項と第13項である。これらはCFC固有の益金算入額を、直接「調整国外所得金額」に算入する特別規定である。

租税特別措置法施行令 第39条の18 第12項
法第六十六条の六第一項各号に掲げる内国法人の各事業年度の所得の金額の計算上同項又は同条第六項若しくは第八項の規定により益金の額に算入された金額（以下この項において「益金算入額」という。）がある場合には、当該益金算入額は、当該内国法人の当該各事業年度に係る法人税法第六十九条第一項に規定する控除限度額の計算については、法人税法施行令第百四十二条第三項本文に規定する調整国外所得金額（当該内国法人が通算法人である場合には、同令第百四十八条第四項に規定する加算前国外所得金額）に含まれるものとする。

ただし、その所得に対して……外国法人税を課さない国又は地域に本店又は主たる事務所を有する外国関係会社に係る益金算入額……については、この限りでない。
→ CFC合算益金算入額150が調整国外所得金額に入る根拠。ただし無税国CFCの場合は除外。
租税特別措置法施行令 第39条の18 第13項
第八項各号に掲げる外国法人税の額のうち法第六十六条の七第一項の規定により外国関係会社に係る内国法人が納付する控除対象外国法人税の額とみなされる金額は、その内国法人の当該各号に定める事業年度に係る法人税法第六十九条第一項に規定する控除限度額の計算については、法人税法施行令第百四十二条第三項本文に規定する調整国外所得金額（当該内国法人が通算法人である場合には、同令第百四十八条第四項に規定する加算前国外所得金額）に含まれるものとする。
→ みなし外税50も調整国外所得金額に入る根拠。

6.3 国外所得金額の算定

措令39条の18⑫⑬により、以下の2つの金額が調整国外所得金額に算入される。

項目金額条文根拠
CFC益金算入額（課税対象金額）150措令39条の18⑫
みなし外税益金算入額50措令39条の18⑬
国外所得金額（CFC由来合計）200
国外所得金額 = CFC益金算入額（150）⑫ + みなし外税（50）⑬ = 200
構造の理解：⑫⑬は一般の「国外源泉所得」（法69条④）を経由せず、直接「調整国外所得金額」（施行令142条③）に算入するバイパス規定である。CFC合算という擬制的な益金を、外国税額控除の限度額計算で国外所得として扱うための架橋規定といえる。

6.4 ⑫の例外規定 ── 無税国CFCの場合

措令39条の18⑫但書は、「外国法人税を課さない国又は地域に本店を有するCFC」の益金算入額を調整国外所得金額から除外する。無税国のCFCは外国法人税が存在しないため、外国税額控除を適用する余地がなく、国外所得金額に含める必要がないからである。

本件では×2年に外国法人税50が課されているため、この例外は適用されない。

7. ×2年：調整国外所得金額と90%キャップ

7.1 調整国外所得金額の定義

法人税法施行令 第142条 第3項
当該事業年度の調整国外所得金額とは、……当該事業年度の法第六十九条第一項に規定する国外所得金額から外国法人税が課されない国外源泉所得に係る所得の金額を控除した金額をいう。ただし、当該金額が当該事業年度の所得金額の百分の九十に相当する金額を超える場合には、当該百分の九十に相当する金額とする。

調整国外所得金額は以下の2段階で計算される。

Step 1: 調整国外所得金額 = 国外所得金額 − 外国法人税非課税の国外源泉所得
Step 2: 90%キャップ = min( Step 1の結果, 所得金額 × 90% )

7.2 本件への適用

CFC由来の国外所得金額200は全て外国法人税が課された所得に対応するため、Step 1での控除はゼロ。

ケースA：親法人にCFC以外の所得がない場合

項目金額備考
所得金額200CFC益金150 + みなし外税益金50
国外所得金額200措令39条の18⑫⑬
外国法人税非課税分の控除0該当なし
90%キャップ = 200 × 90%180
調整国外所得金額180min(200, 180)
90%キャップの影響：親法人にCFC以外の所得がない場合、国外所得金額(200)が所得金額(200)と一致するため、必ず90%キャップが作動し、調整国外所得金額は所得の90% = 180に圧縮される。これは国内源泉の法人税財源を最低10%確保するための政策的措置である。

ケースB：親法人に十分な国内所得がある場合

例えば、CFC益金のほかに国内所得800がある場合：

項目金額備考
所得金額1,000CFC益金200 + 国内所得800
国外所得金額200措令39条の18⑫⑬
90%キャップ = 1,000 × 90%900
調整国外所得金額200min(200, 900) → キャップ非抵触
実務上の意味：親法人に十分な国内所得がある場合、90%キャップは作動せず、調整国外所得金額は200となる。多くの実務ケースではこちらに該当する。

8. 控除限度額の最終計算

法人税法施行令 第142条 第1項
法第六十九条第一項に規定する政令で定めるところにより計算した金額は、……内国法人の各事業年度の所得に対する法人税の額……に、当該事業年度の所得金額のうちに当該事業年度の調整国外所得金額の占める割合を乗じて計算した金額とする。
控除限度額 = 法人税額 × ( 調整国外所得金額 ÷ 所得金額 )

ケースA：CFC以外の所得なし

項目金額
所得金額200
調整国外所得金額180
法人税額（23.2%想定）46.4
控除限度額 = 46.4 × 180/20041.76
みなし外税50 vs 控除限度額41.76控除限度超過 8.24

90%キャップにより控除限度額が圧縮されるため、みなし外税50のうち8.24が当期に控除できず、控除限度超過額として3年間繰り越される（法69条②）。

ケースB：国内所得800がある場合

項目金額
所得金額1,000
調整国外所得金額200
法人税額（23.2%想定）232
控除限度額 = 232 × 200/1,00046.4
みなし外税50 vs 控除限度額46.4控除限度超過 3.6

国内所得が十分あっても、控除限度額46.4（= 200/1,000 × 232）に対してみなし外税50が上回るため、3.6は超過額として繰越。

なぜ50全額を控除できないか：控除限度額の計算は「所得金額に占める国外所得金額の割合」に法人税率を乗じたものであるため、日本の法人税率（23.2%）が外国の実効税率（本件では50/250=20%ないし50/300≒16.7%）を上回る場合にのみ全額控除可能。CFC合算では、繰越欠損金控除と納付法人所得税控除により適用対象金額（=国外所得の基礎）が圧縮されるが、みなし外税は圧縮前の外国法人税額全額（50）が対象となるため、控除限度額との間にギャップが生じやすい。

9.2 実務上の留意点

（1）持株割合が100%未満の場合

持株割合がp%の場合：課税対象金額 = 150 × p%、按分比率 = (150×p%) / 150 = p%。みなし外税 = 50 × p%。国外所得金額 = 150×p% + 50×p% = 200×p%。

（2）×1年の外国法人税の不救済

×1年にCFCが外国法人税を納付していた場合でも、適用対象金額がゼロであるため措法66条の7①のゲートが閉じ、当該外国税は日本側で一切認識されない。控除限度超過額としての繰越（法69条②）も不可能である。これはCFC税制の構造的限界である。

（3）基準所得金額と利益の乖離への注意

本件では利益250に対し基準所得金額が300と50の乖離がある。みなし外税の按分計算（措令39条の18③）では基準所得金額ではなく「調整適用対象金額」が分母となるため、この乖離は按分比率に影響しない。ただし、基準所得金額が大きいほど適用対象金額も大きくなり、国外所得金額が増加する。

（4）控除しきれない場合の繰越

みなし外税50が控除限度額を超過した場合、超過額は法69条②に基づき3年間繰り越すことができる。翌期以降に控除余裕額があれば順次控除される。
