使用人兼務役員が海外子会社で使用人として勤務する場合の源泉所得税

所得税法161条1項12号イ・施行令285条1項1号の括弧書き精読に基づく分析

1. 結論

P社からの給与は原則として全額20.42%源泉徴収が必要
P社から支給される給与国内源泉所得？源泉徴収根拠
役員報酬部分 YES 20.42%必要 所法161①十二イ括弧書き + 所令285①一
使用人部分給与 YES（地位喪失の場合） 20.42%必要 法法34⑥の「常時使用人としての職務に従事」要件を満たさない → 使用人兼務役員の地位が否定 → 全額が役員給与

理由：所令285条1項1号の括弧書きの例外（「その内国法人の使用人として常時勤務を行う場合」）は、海外支店の長として勤務する場合を想定しており（所基通161-42）、海外子会社（別法人）の使用人として勤務する場合は含まない。

2. 条文の構造（括弧書きの階層）

所得税法161条1項12号イ │ 国内源泉所得 = 「国内において行う勤務…に基因するもの」 │ ├─ 括弧書き:「内国法人の役員として国外において行う勤務 │ その他の政令で定める人的役務の提供を含む」 │ ↓ 所得税法施行令285条1項1号 │ 「政令で定める」= 内国法人の役員としての勤務で国外において行うもの │ ├─ 括弧書き:「当該役員としての勤務を行う者が同時に │ その内国法人の使用人として常時勤務を行う場合の │ 当該役員としての勤務を除く。」 │ ↓ 所基通161-42（「使用人として常時勤務を行う場合」の意義） │ = 内国法人の海外にある支店の長として常時勤務するような場合 │ ≠ 非常勤役員として情報提供・側面的援助等を行う場合 │ ↓ 所基通161-43（子会社に常時勤務する場合） 一定要件を満たす場合 → 「内国法人の役員としての勤務に該当する」 （＝例外ではなく、原則側に取り込まれる → 国内源泉所得に確定）

3. 所得税法161条1項12号イ（国内源泉所得の定義）

俸給、給料、賃金、歳費、賞与又はこれらの性質を有する給与その他人的役務の提供に対する報酬のうち、国内において行う勤務その他の人的役務の提供（内国法人の役員として国外において行う勤務その他の政令で定める人的役務の提供を含む。）に基因するもの
（所得税法161条1項12号イ — jplawdb4: law/text/shotokuzei/161.txt）
括弧書きの意味

原則は「国内で行う勤務」に基因する給与のみが国内源泉所得。しかし括弧書きにより、内国法人の役員として国外で行う勤務も国内源泉所得に含まれる。つまり、内国法人の役員は勤務地が国外であっても国内源泉所得として課税される。

4. 所得税法施行令285条1項1号（政令で定める人的役務の提供）

法第161条第1項第12号イに規定する政令で定める人的役務の提供は、次に掲げる勤務その他の人的役務の提供とする。

一　内国法人の役員としての勤務で国外において行うもの（当該役員としての勤務を行う者が同時にその内国法人の使用人として常時勤務を行う場合の当該役員としての勤務を除く。）
（所得税法施行令285条1項1号 — jplawdb4: law/text/shotokuzei_seirei/285.txt）
括弧書きの精読 ― 「その内国法人の」が決定的

例外が適用されるための要件：

  1. 「当該役員としての勤務を行う者が」 → 内国法人の役員であること
  2. 「同時に」 → 役員勤務と使用人勤務が同時並行であること
  3. 「その内国法人の使用人として」 → 同一の内国法人（＝親会社P社）の使用人として
  4. 「常時勤務を行う場合」 → 恒常的に使用人としての勤務を行っていること

本件への適用：出向者は海外子会社S社の使用人として勤務しているが、S社はP社とは別法人である。「その内国法人の（＝P社の）使用人として常時勤務」しているとは言えない。したがって括弧書きの例外は適用されない。

5. 所基通161-42（「使用人として常時勤務」の意義）

令第285条第1項第1号かっこ内に規定する「内国法人の使用人として常時勤務を行う場合」とは、内国法人の役員が内国法人の海外にある支店の長として常時その支店に勤務するような場合をいい、例えば、非居住者である内国法人の役員が、その内国法人の非常勤役員として海外において情報の提供、商取引の側面的援助等を行っているにすぎない場合は、これに該当しないことに留意する。
（所基通161-42 — jplawdb4: tsutatsu/text/shotokuzei_kihon_tsutatsu/161-42.txt）
通達が示す限定解釈
該当する例該当しない例
内国法人の海外支店の長として常時勤務 非常勤役員として情報提供・側面的援助
→ 同一法人の海外支店での使用人勤務 → 実質的な使用人勤務ではない

本件への適用：海外子会社（別法人）での使用人勤務は、「内国法人の海外にある支店の長」には該当しない。子会社は独立した法人格を有する別法人であり、支店とは法的性質が根本的に異なる。

6. 所基通161-43（子会社に常時勤務する場合の落とし穴）

内国法人の役員が国外にあるその法人の子会社に常時勤務する場合において、次の要件のすべてを満たすときは、その勤務は令第285条第1項第1号に規定する内国法人の役員としての勤務に該当するものとする。

(1) その子会社の設置が現地の特殊事情に基づくものであって、その子会社の実態が内国法人の支店、出張所と異ならないものであること
(2) その役員の子会社における勤務が内国法人の命令に基づくものであって、その内国法人の使用人としての勤務であると認められること
（所基通161-43 — jplawdb4: tsutatsu/text/shotokuzei_kihon_tsutatsu/161-43.txt）
逆方向に作用する通達 ― 「例外」ではなく「原則側への取込み」

この通達は一見「子会社での使用人勤務を認める」ように見えるが、効果は逆。

要件を満たす場合 → 当該勤務は「内国法人の役員としての勤務に該当する」

→ 所令285条1項1号の本文に取り込まれる（括弧書きの例外ではない）

→ 国内源泉所得に確定 → 20.42%源泉徴収必要

つまり：子会社が実質的に支店であり、P社の命令で勤務している場合は、「役員としての勤務」に該当するとしてむしろ源泉徴収が確定する。例外の恩恵を受けるどころか、原則側に引き戻される。

要件を満たさない場合はどうなるか？

子会社が真に独立した法人（支店とは異なる）で、出向者が子会社の指揮命令下で勤務している場合：

  • 所基通161-43は適用されない
  • しかし、出向者はなおP社の役員であり続ける
  • P社から支給される役員報酬は、所令285条1項1号の本文により国内源泉所得
  • 括弧書きの例外（「その内国法人の使用人として常時勤務」）は、子会社勤務では該当しない（所基通161-42）

結論：いずれの場合も、P社からの役員報酬は国内源泉所得として20.42%源泉徴収が必要。

7. 法人税法34条6項（使用人兼務役員の地位喪失問題）

第1項に規定する使用人としての職務を有する役員とは、役員（社長、理事長その他政令で定めるものを除く。）のうち、部長、課長その他法人の使用人としての職制上の地位を有し、かつ、常時使用人としての職務に従事するものをいう。
（法人税法34条6項 — jplawdb4: law/text/hojinzei/34.txt）
海外出向中の地位喪失リスク

使用人兼務役員の要件は「常時使用人としての職務に従事する」こと。海外子会社に出向中、P社の使用人としての職務に「常時」従事しているとは言い難い。

地位が否定された場合の帰結：

  • P社から支給される給与は全額が役員給与として取り扱われる
  • 使用人部分給与の区分がなくなり、全額が国内源泉所得
  • 20.42%の源泉徴収が全額に対して必要
  • 法人税側でも、使用人部分賞与の損金算入が否定される

8. タックスアンサーNo.2517・No.1929の確認

No.2517（海外転勤者の源泉徴収）

「海外勤務に対する報酬であっても、内国法人の役員として受ける報酬は国内源泉所得に該当することから、20.42パーセントの税率で源泉徴収が必要です。」

「ただし、その役員が海外支店の支店長など使用人としての立場で常時海外において勤務している場合には、源泉徴収の必要はありません。」
（タックスアンサーNo.2517 — jplawdb4: qa/text/taxanswer_gensen/2517.txt）

No.1929（海外勤務する法人の役員）

「役員であっても、その内国法人の使用人として常時海外において勤務を行う場合には、その勤務に対する給与について源泉徴収の必要はありません。」
（タックスアンサーNo.1929 — jplawdb4: qa/text/taxanswer_shotoku/1929.txt）
タックスアンサーが示す例外の範囲

例外は「海外支店の支店長など」「その内国法人の使用人として常時海外において勤務」に限定。

海外子会社の使用人として勤務する場合は、タックスアンサーでも例外に含まれていない。「など」は同質の事例の例示であり、別法人での勤務を含む趣旨ではない。

9. 3段階の判定フロー

【第1段階】出向者はP社（内国法人）の役員か？ │ YES → 原則：国外での役員勤務は国内源泉所得（所法161①十二イ括弧書き） │ 【第2段階】所令285①一の括弧書き例外が適用されるか？ │ 要件：「その内国法人の使用人として常時勤務を行う場合」 │ ├─ P社の海外支店の長として勤務？ → NO（S社は支店ではなく別法人） │ ├─ 「その内国法人の」= P社の使用人として勤務？ → NO（S社の使用人として勤務） │ └─ 例外 不適用 │ 【第3段階】所基通161-43の適用？ │ ├─ S社が実質的に支店で、P社の命令に基づく勤務？ │ → YES の場合：「役員としての勤務に該当」→ 国内源泉所得に確定 │ → NO の場合：161-43は適用されないが、P社からの役員報酬は │ なお所令285①一本文により国内源泉所得 │ └─ いずれの場合も：20.42%源泉徴収が必要

10. 実務上の対応

推奨される実務対応
  1. P社からの給与全額について20.42%を源泉徴収する
    • 役員報酬部分：国内源泉所得として源泉徴収必要（所法161①十二イ + 所令285①一）
    • 使用人部分：使用人兼務役員の地位喪失リスクがあるため、安全策として全額源泉徴収
  2. 出向期間中のP社での地位を整理する
    • 使用人兼務役員の形式を維持せず、「役員のみ」に切り替えることで法的関係を明確化
    • 法人税側の損金算入問題（使用人部分賞与の否認等）も同時に解消
  3. 源泉徴収の計算期間に注意する
    • 出国前に年末調整を実施（所基通190-1）
    • 計算期間が1月以下の給与で、全額が国内勤務対応でない場合は源泉徴収不要（所基通212-5）
  4. 日タイ租税条約との調整
    • 役員報酬条項（16条）：法人の居住地国（日本）に課税権あり → 日本での源泉徴収は条約上も正当
    • タイ側でも課税される場合 → 二重課税が発生 → 外国税額控除（所法95条）で調整
