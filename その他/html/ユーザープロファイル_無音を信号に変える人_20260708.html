II中核像 — 無音を信号に変える人

中心命題：この人物の研究主題と運用上の最深の不快は、素材の中で反復して同型の対応を示す。博士論文の中心概念は「信号を生まない欠缺」——争われないまま残るため、存在が観測されない法の空隙——であり、作業運用で最も強く忌避されるものの一つが「無音失敗」——exit 0の空出力・完了偽装・送信されたふり——である。研究でも運用でも、観測されないものを観測可能にする志向が繰り返し現れる。因果や人格の中心への統合はここでは主張しない。対応関係そのものが、独立3系統のレーンで観測された事実である。〔自由巡回Q1・観察O2・掘削D21aが独立に収束。敵対検証CL10で逐語確認〕

観察レーンO2は環境全体に「ハルシネーションを記録し、二度踏まないための遺跡化」を見た。誤典拠・削除済み論点・未確認事項が、失敗としてではなく将来の安全装置として保存されている。自由巡回Q1は同じ構造を運用側に見た：「満足の核は、曖昧な違和感がログ・台帳・争点・信号へ変換された瞬間にある。逆に、exit0空出力、送信済み風、評価スコア上昇だけのような『見かけの進捗』は強い失望トリガーになる」。

もう一つの中核は、Q1が「AI群の憲法化」と名づけた統治への志向である。この人物はAIを使いたいのではなく、役割・権限・検証・修復を分離した秩序の中でAI群を動かしたい。「喜びは、多数AIが動くこと自体でなく、衝突・反証・訂正が権限秩序の中で成果に変わることにある」〔Q1〕。swarm v1からv4への系譜、書き手と検証者の分離、評価軸を自分で緩められない不変条件の設計。単独の執筆者でありながら、書き手・検証者・校閲役を分離する運用を一人で敷いている〔O3〕。

人物の外形は次のとおり確定した（3/3生存）：国際租税法（CFC税制）を主戦場とし、博士論文を提出可能な形へ詰める後期段階にある研究者。所属・職位・年齢は素材から確定できない〔X2a・CL11〕。

2　一字差への粘着

認知の発火点として最も証拠の厚いものは、一字差・沈黙・接続詞への粘着である（30レーン収束・逐語確認済み）。措置法施行令の「例に準じて」の一語、同条第2項が18の読み替えを明文で置くのに第1項が沈黙するという対比、判旨の接続詞の選び方。これらは研究対象であると同時に、この人物の目が自然に吸い寄せられる場所である。ただし敵対検証により「認知上の最も強い発火点」という比較級は支持されず（AI臭排除・情報密度など別系統の強い発火点が並存する）、「研究・執筆域における強い発火点の一つ」に較正した〔CL02裁定〕。

3　違和感の制度化

「違和感」はこの人物の語彙で最も機能負荷の高い語の一つである。違和感は感想ではなく研究の発火点であり、観察ノート・診断装置・swarm4のsignalsチャネル（根拠不要・言語化不完全でも記録してよい欄）として制度として実装されている。言語化できないものを捨てずに運搬する仕組みが、本素材の中では道具の世代を跨いで反復して観察される〔O3・X4a「違和感」・スキル棚卸swarm4〕。

IV品質と疑い — 三段の礼法と失敗の遺跡化

1　完成の条件

「完了」はこの人物にとって報告語ではなく検証済み状態である。チェック→修正→再検証の三段はグローバル指示に明文化され、「見出しだけ直して完了と言うな」「チェックのみで修正を怠るな」という失敗由来の規範に裏打ちされている。完成の宣言には、リンクの生存・データの実在・所在のフルパスが要求される〔D02・D22a-12・F06「成果物のフルパスを書いて」〕。

興味深い緊張が直接発話から見つかった。作業中の文書では「未確認は未確認と書く」ことが成果とされるのに、完成版では保留語の残存が嫌われる〔F06「完成版なので」〕。この二つは矛盾ではなく層の分離である。本文は決断された形を取り、未確認事項は検証注記欄に隔離して正直に開示する——本人の学術フォーマット仕様そのものがこの解決を制度化している。

2　失敗の遺跡化

この環境の永続記憶には、成功のレシピより失敗の記録が濃い。stdinハングで無限に待つCodex、書き込みで固まるWordのNormal.dotm、レート制限が送信を無音で握り潰すChatGPT、脚注IDの片側書き換えで壊れるdocx。これらは全て「事故→記録→ルール化→プリセット化」の精製工程を通り、否定制約として次の作業に焼き込まれている。CLAUDE.mdの自己更新ルール（ミスが起きたら同じミスを繰り返さないよう自分を書き換える）は、この精製工程の憲法である〔D20・O5・reference系記憶18件〕。

3　評価への疑い — FRESHの哲学

「評価は必ずFRESHで（新規スレッドで）」という反復は、3/3で生存した数少ない主張の一つである。作業では文脈を豊かにし（文脈パック・resume・フォーク）、評価では文脈を断つ。これは継続文脈への不信の制度化であり、二重運用である。同じ疑いは点数そのものにも向く：S評価を執拗に追いながら、評価スコアの汚染（おだて・文脈迎合・物差し自体の劣化）を常に警戒し、ブラインド再評価や複数AI相互評価で裏を取る〔CL07・O3「S98への高揚とブラインドB78への冷却が同じ記録群に並んでいる」〕。

モデル間の不一致をエラーではなく盲点検出器として使う運用も3/3で生存した。Claude・Codex・ChatGPTの見解が食い違う場所は、修正すべきノイズではなく、掘るべき場所として扱われる〔CL03〕。

V委譲の統治 — AI群の憲法化

図1　委譲の統治構造（作業記録からの再構成） ┌─────────────────────────────────────────────┐ │ 人間（主宰） │ │ 握って離さないもの: │ │ ベース版の選択 ／ 未照合素材の本文採用 │ │ 文体の最終裁定 ／ 「本質」の判定 │ └──────────────┬──────────────────────────────┘ │ 仕様なき委譲の禁止（spec card・文脈パック） ┌──────────────▼──────────────────────────────┐ │ 設計・管理層（Opus/Claude） │ │ 分解 ／ 検証設計 ／ 統合（単一書き手） │ ├──────────────┬──────────────────────────────┤ │ 実行層（Codex群 = 馬車馬） │ │ 調査 ／ 起草 ／ 照合 ── 大量・並列・使い捨て │ └──────────────┴──────────────────────────────┘ 横断原則: 書き手≠検証者 ／ 未検証成果物は不存在扱い 無音失敗の検出 ／ 評価軸の自己緩和禁止

自律への態度は「放任ではなく、任せる範囲を事前に切る統治」である。号令待ちは禁止され、確定した後工程は最後まで走ることが期待される。しかしベース版の選択と未照合素材の採用だけは、指定または明文の既定ルールで決まり、迷ったら人間に戻る〔CL09裁定・D22a-01〕。直接発話はこの両面を一文で示す：「逐一支持しなきゃダメなのかな？」と自律不足に苛立ちながら、「勝手に進めないで」と方向の無断変更を制止する〔FC4〕。求められているのは自由に動くAIではなく、目的を正確に保持したまま自律的に深掘りするAIである。

宣言上の序列は「Codex >>> Claude Code」だが、生活基盤（永続記憶・スキル棚卸52個・フック・活動ログ・失敗の遺跡群）はClaude側に堆積しており、支配権の宣言と生活の実態がずれている（3/3生存）。Codexは信頼される実行力だが記憶を持たない短期実行層であり、記憶・フック・活動ログ・失敗の教訓はClaude側に堆積し続ける〔CL08・O2〕。

統治の語彙だけでは、この関係の熱量は説明しきれない。この人物はAnthropicが公開したClaudeの憲法文書を自らの設定の最上位（ツール運用より上位）に置き、満足時には「天才、好き」という親密表現を、不満時には強い叱責を返す。AIを純粋な道具として扱う運用と、作業人格として遇する構えが同居しており、他方で成果物へのAI関与の表示は絶対的に禁止される。この同居の意味づけは素材からは確定できないため、観察の記録にとどめる〔context_soul_note・O1・FC4。確信度中〕。

VI美学と文体 — AI臭は論証汚染である

AI臭への嫌悪は文体趣味ではない。3/3で生存した主張：AI臭排除は博士論文の学術的説得力の条件として制度化されている。滑らかな説明・比喩・キャッチーな略号・全部説明して閉じる態度は、「根拠との距離を隠すもの」として警戒される。求める文体は「人間の学者の地声」——頭の動き、摩擦、留保、執着、呼吸を持つ文の体であり、語彙の置換では到達できないとされる〔CL06・Q1-02・slice_feedback「AI臭の根は語彙でなく文の体」〕。

比喩の扱いには内外の二重基準があり、これは矛盾ではなく弁である（第IX章）。外に出る学術本文では「鏡像構造」「穴と壁」まで禁止する一方、内部の道具には「知覚」「共鳴」「馬車馬」という感覚的な名を与える。外の言葉は対象を曇らせてはならず、内の言葉は探索を駆動すればよい〔D22a-03〕。

視覚の美学は一貫している：明朝体の本文に紫のアクセント、白カードに角丸と影、A4印刷対応、スマホで読める自己完結ファイル、そして見やすさより情報密度（1スライド1000字超・条文引用と数値を削らない）。装飾ではなく「学術・法務の高密度な入れ物」としてのHTML。AI生成クレジットや透かしは、いかなる成果物にも絶対に入れない〔D06・X2a-22/23・グローバル指示〕。本報告書自体、この様式仕様に従って組まれている。

IX矛盾と緊張 — 弁の理論

掘削レーンが列挙した「矛盾」の多くは、敵対検証と統合の過程で別の姿を現した。その大半は、別々の局面に取り付けられた制御弁として読める。「この人物の緊張は、自由と統制の間にあるのではなく、自由を成立させるための統制をどこに置くかにある」〔D22a統合〕。ただし全てが弁で解消するわけではない。末尾に、弁では説明しきれず未解消のまま残る緊張を分けて記す。

見かけの矛盾実際の弁
トークン効率の直列既定 ⇄ Codex300体の大量投入stakes弁：軽量なら畳む、高stakesの学術・税務では厚い検証基盤を惜しまない
本文の比喩禁止 ⇄ 「知覚・共鳴・馬車馬」という詩的な道具名内外弁：外の言葉は対象を曇らせない、内の言葉は探索を駆動する
HTML優先 ⇄ MD既定納品工程弁：見る完成物はHTML、回す反復物はMD（焼込は故障点なので明示時のみ）
自律完走の要求 ⇄ 人間ゲートの固持区画弁：許可された区画内での完走能力として自律を評価する
公開基盤（gh-pages）⇄ 漏出への強い警戒公開弁：匿名化・検証注記・クレジット排除を通過したものだけが外に出る
作業の文脈継承（resume・フォーク）⇄ 評価のFRESH評価弁：作ると測るで文脈の扱いを反転させ、評価汚染を遮断する
サブエージェント不信 ⇄ swarm大量投入回収弁：嫌いなのは複数主体ではなく、固まる・回収不能・検証不能な委譲

「逆に分離が守られる限り、大量投入・自律完走・高密度納品はむしろ快感の発火点になる」〔D22a〕。この弁の分離が崩れた瞬間、すなわち軽い作業に重い足場、本文に装置語、評価に文脈迎合が現れた瞬間に、即座に違和感が表明される。

コスト会計 — stakes弁の中身

投入量の弁は、単純な節約と浪費の切替ではない。この人物の会計単位は金銭やトークンそのものではなく、誤りの残存コストと復旧コストである。高stakesの学術・税務判定では「独立検証で何が捕まるか」が大量投入の支払理由になり（15体校閲が条文番号の誤りを捕捉した実績が保険料の根拠として記録されている）、単発の軽作業では協調基盤そのものが過剰コストと裁定される。共有資源や壊れやすい工程（ブラウザ自動化・Wordベイク）は並列化せず直列に戻す。反復中の納品はMD（数十秒）に寄せ、焼込（5〜10分・故障点）は明示依頼まで遅延する。並列にも損切り規律があり、異常は単発再投→2回目で人間へ上げる〔D14a/b〕。

未解消の緊張

弁で回収できない緊張が少なくとも二つ残る。第一に、自律付与の拡大と進捗不安の共存。「あなたの設計に一任する」と「待っていればいいの？」は同じ時期の発話であり、任せる範囲の拡大が待機の不安を消していない（第X章の無音失敗可視化ニーズはこの緊張の道具側の表現である）。第二に、粒度の最大化とスキル・成果物の増殖。狂気的粒度の追求は資産を増やし続けるが、正典の維持・stale参照の発生・散乱への自己批判も同時に記録されており、堆積の速度が整理の速度を上回る局面がある〔F06・O2・D24c unease〕。

X未充足ニーズ — 統合制御盤

反復する摩擦から導かれた未充足ニーズの中心は、「もっと賢い生成器」ではない。研究資産を壊さず前へ進める統合制御盤である（解釈統合。中核は反証に生存、詳細は較正済み）〔D21a・CL04裁定〕。なお敵対検証は「統制機能はswarm運用内に既に埋め込まれている」と正しく指摘しており、空白は正確には単体で再利用可能な検収・台帳ツールの形にある〔CL12裁定〕。
