シンガポール子会社のCFC合算漏れと外国税額控除

国外所得金額そのものではなく、CFC特則による「調整国外所得金額」への入り方までを条文引用で整理する。

結論

まず確定できること

×1年は赤字年なので、通常はCFC合算による益金算入が生じず、[租税特別措置法66条の7第1項](https://laws.e-gov.go.jp/document?lawid=332AC0000000026) の「みなし控除対象外国法人税」も発動しない。したがって、×1年のシンガポール税額10万円は、その年単独では日本側の外国税額控除に入りません。

一方、×2年は正のCFC合算額が出るため、同年のシンガポール税額14万円は、同条1項により親会社が納付する控除対象外国法人税の額とみなされ得ます。

ただし、設例の数値だけでは「最終金額」は1本に確定しない

分岐点は、ユーザー提示の「×1年 ▲100万円 / ×2年 300万円」が、どの段階の数字かです。CFCでは [措令39条の15](https://laws.e-gov.go.jp/document?lawid=332CO0000000043) により、(1) 基準所得金額を計算し、(2) そこから欠損金額と法人所得税額を調整する二段階構造になっているため、現地帳簿上の利益・税務所得・基準所得金額を混同すると答えがずれます。

実務上の読み筋

今回のようなCFC絡みのFTCでは、通常の [法人税法69条1項](https://laws.e-gov.go.jp/document?lawid=340AC0000000034) の国外所得金額論だけでは足りず、[措令39条の18第12項・第13項](https://laws.e-gov.go.jp/document?lawid=332CO0000000043) により、CFC益金算入額とみなし外税額が控除限度額計算上の調整国外所得金額に入る点が核心です。

条文構造

1. 通常の外国税額控除の出発点

法人税法69条1項 抜粋

「内国法人が各事業年度において外国法人税を納付することとなる場合には、…当該事業年度の国外所得金額…に対応するものとして…計算した金額を限度として、その外国法人税の額…を…法人税の額から控除する。」

法人税法施行令141条の2第1項 抜粋

「国外所得金額」は、各事業年度の各国外源泉所得に係る所得金額の合計額（零未満なら零）である。

法人税基本通達16-3-19の2 抜粋

国外所得金額に入る所得金額は「現地における外国法人税の課税上その課税標準とされた所得の金額そのものではなく」、日本法ベースで計算した課税標準相当額である。

2. CFC税制が入るときの特則

租税特別措置法66条の7第1項 抜粋

「前条第一項…の規定の適用を受ける場合には」、外国関係会社の所得に対して課される外国法人税の額のうち課税対象金額に対応する部分は、親会社が納付する「控除対象外国法人税の額とみなして」、法人税法69条を適用する。

租税特別措置法66条の7第2項 抜粋

同項の規定により控除対象外国法人税の額とみなされた金額は、政令で定める事業年度の所得金額の計算上、「益金の額に算入する」。

措令39条の18第12項・第13項 抜粋

CFC合算により益金算入された金額と、66条の7第1項でみなし外税となった金額は、いずれも法人税法69条1項の控除限度額計算における「調整国外所得金額に含まれる」。

3. CFC合算額そのものの計算

租税特別措置法66条の6第2項4号 抜粋

適用対象金額は、基準所得金額を基礎として、前7年内の欠損金額及び税額調整を加えた金額である。

措令39条の15第5項 抜粋

適用対象金額は、基準所得金額から、(1) 前7年内の欠損金額、(2) 当該事業年度に納付することとなる法人所得税の額、を控除した残額とする。

重要な読み方

[措令39条の15第1項・第2項](https://laws.e-gov.go.jp/document?lawid=332CO0000000043) で基準所得金額を作り、その後に同条5項で欠損金額と法人所得税額を控除する。このため、現地税額は基準所得金額段階では加算され、適用対象金額段階では控除されて相殺されることがある。ここを飛ばして「300−100−14」と置くと、条件によってはズレます。

なぜ数字が分かれるのか

ご提示の「所得▲100万円 / 300万円」が、次のどちらかで結果が変わります。

読み方 意味 影響
パターンA 提示額は、現地帳簿ベースないし税引後ベースの概算値であり、39条の15第1項・第2項による税額加減算をまだ経ていない 現地税額は基準所得金額で加算され、適用対象金額で控除されるため、当期税額が相殺される方向で読む
パターンB 提示額は、すでにCFC計算上の基準所得金額に近い値として与えられている そのまま5項控除に入れるため、当期税額14万円を別途控除する読みになる

実務では、現地申告書だけでなく、試算表・税効果仕訳・納税計算書を見ないとどちらか断定できません。

設例の2パターン整理

パターンA: 提示額を現地帳簿ベースの概算値として読む場合

この読み方では、×1年の10万円は基準所得金額段階で加算される一方、翌年に繰り越す欠損金額は90万円に圧縮されます。×2年の14万円も、当期の適用対象金額計算では相殺される方向になります。

×1年 欠損金額 ≒ 100万円 − 10万円 = 90万円 +×2年 適用対象金額 ≒ 300万円 − 90万円 = 210万円 +×2年 みなし外税額 = 14万円（100%保有前提） +控除限度額計算に入る調整国外所得金額のベース ≒ 210万円 + 14万円 = 224万円

この読み方だと、前期の税額10万円は「その年のFTC」にはなりませんが、前期欠損金額を100万円ではなく90万円にすることで、翌年のCFC合算額を10万円押し上げます。

パターンB: 提示額をすでに基準所得金額ベースと読む場合

この読み方では、×1年の欠損金額は100万円のまま、×2年は [措令39条の15第5項](https://laws.e-gov.go.jp/document?lawid=332CO0000000043) の文言どおりに14万円も控除する整理になります。

×1年 欠損金額 = 100万円 +×2年 適用対象金額 = 300万円 − 100万円 − 14万円 = 186万円 +×2年 みなし外税額 = 14万円（100%保有前提） +控除限度額計算に入る調整国外所得金額のベース = 186万円 + 14万円 = 200万円

前回の簡潔回答で示した「200万円台前半」というイメージは、このパターンBに近い発想です。

どちらが実務上有力か

条文構造だけでいえば、パターンAの「当期法人所得税は基準所得金額段階で加算され、適用対象金額段階で控除されるため相殺される」という整理の方が自然です。これは、既存のCFC実務資料でも繰り返し使われる整理です。

ただし、ユーザー提示値が何を指す数字かが明示されていない以上、申告・修正申告では、現地帳簿から39条の15第1項又は第2項に沿って基準所得金額を再計算するのが安全です。

このケースで確定してよい最低限の結論

どのパターンでも共通するのは次の2点です。

1. ×1年の10万円は、その年単独ではFTCにならない。

2. ×2年の14万円は、CFC合算が立てば66条の7第1項によりFTC候補になる。

控除限度額との接続

法人税法施行令142条1項・3項 抜粋

控除限度額は「法人税額 ×（調整国外所得金額 ÷ 所得金額）」で計算する。もっとも、調整国外所得金額は所得金額の90%相当額を上限とする。

したがって、最終的な当期外国税額控除額は、14万円がそのまま落ちるとは限らず、

当期外国税額控除額 = min( 14万円, 控除限度額 )

で決まります。ただし、今回の設例はシンガポール税額が14万円と小さいため、日本側で十分な所得と法人税額があれば、通常は14万円全額が当期控除に収まる可能性が高いです。

正確な控除限度額を出すには、日本親会社の当期所得金額、他の税額控除、地方法人税・住民税の情報が必要です。

実務で確認すべき点

  • シンガポール子会社の持株割合が100%か。100%でないなら、課税対象金額もみなし外税額も持分按分になる。
  • ×1年の10万円、×2年の14万円が、39条の15第5項2号の「法人所得税」に当たる税か。
  • 提示の「所得」が、現地帳簿利益・現地税務所得・CFC基準所得金額のどれか。
  • ×1年と×2年で、39条の15第1項（本邦法令基準）か第2項（本店所在地国法令基準）かの選択が同じか。
  • 配当調整、控除対象配当等、部分合算論点がないか。
  • 修正申告時に、66条の7関係明細、別表六、別表十七（三の二）等の整合を取り直しているか。
