シンガポール子会社のCFC合算漏れと外国税額控除

国外所得金額そのものではなく、CFC特則による「調整国外所得金額」への入り方までを条文引用で整理する。

結論

まず確定できること

×1年は赤字年なので、通常はCFC合算による益金算入が生じず、[租税特別措置法66条の7第1項](https://laws.e-gov.go.jp/document?lawid=332AC0000000026) の「みなし控除対象外国法人税」も発動しない。したがって、×1年のシンガポール税額10万円は、その年単独では日本側の外国税額控除に入りません。

一方、×2年は正のCFC合算額が出るため、同年のシンガポール税額14万円は、同条1項により親会社が納付する控除対象外国法人税の額とみなされ得ます。

ただし、設例の数値だけでは「最終金額」は1本に確定しない

分岐点は、ユーザー提示の「×1年 ▲100万円 / ×2年 300万円」が、どの段階の数字かです。CFCでは [措令39条の15](https://laws.e-gov.go.jp/document?lawid=332CO0000000043) により、(1) 基準所得金額を計算し、(2) そこから欠損金額と法人所得税額を調整する二段階構造になっているため、現地帳簿上の利益・税務所得・基準所得金額を混同すると答えがずれます。

実務上の読み筋

今回のようなCFC絡みのFTCでは、通常の [法人税法69条1項](https://laws.e-gov.go.jp/document?lawid=340AC0000000034) の国外所得金額論だけでは足りず、[措令39条の18第12項・第13項](https://laws.e-gov.go.jp/document?lawid=332CO0000000043) により、CFC益金算入額とみなし外税額が控除限度額計算上の調整国外所得金額に入る点が核心です。

条文をつないで読む

この論点は、条文を個別に読むより、「通常の外国税額控除」→「CFC合算が立つか」→「そのとき外国税額控除にどう接続するか」→「最後に控除限度額にどう乗るか」という順で一続きに読む方が分かりやすいです。以下では、その流れに沿って条文をつないで整理します。

1. 出発点は法人税法69条の通常ルール

法人税法69条1項 + 法人税法施行令141条の2第1項

内国法人が外国法人税を納付するときは、その事業年度の「国外所得金額」に対応するものを限度として外国税額控除を行う。ここでいう国外所得金額は、各国外源泉所得に係る所得金額の合計額であり、零未満なら零とされる。

法人税基本通達16-3-19の2

国外所得金額に入る所得は、現地で課税標準になった数字をそのまま使うのではなく、日本法ベースで計算し直した金額で捉える。

したがって、通常の世界では「現地で税金を払った」というだけでは足りず、日本の法人税法69条が見ている国外所得金額に、その所得がきちんと入っている必要があります。

2. ただし今回は通常ルールだけでは終わらず、先にCFC合算が立つかを見ます

租税特別措置法66条の6第2項4号

外国関係会社の所得を親会社に合算する際の「適用対象金額」は、基準所得金額を出発点にしつつ、前7年内の欠損金額や税額調整を反映して計算する。

租税特別措置法施行令39条の15第1項・第2項・第5項

まず基準所得金額を計算し、その後で欠損金額と当期法人所得税額を控除して、最終的な適用対象金額を出す。

ここがこの設例の核心です。CFCの世界では、「所得300万円」がそのまま合算額になるわけではなく、39条の15の二段階計算を通るので、前期赤字や当期税額の入り方で数字が動きます。

逆にいうと、66条の7の外国税額控除論に進めるのは、66条の6と39条の15を通した結果として、まず日本側に合算される正の課税対象金額が立ったときだけです。

3. CFC合算が立ったときに、66条の7が69条へ橋を架けます

租税特別措置法66条の7第1項

66条の6第1項の適用を受ける場合には、外国関係会社に課された外国法人税のうち、その課税対象金額に対応する部分を、親会社が納付する控除対象外国法人税の額とみなして、法人税法69条を適用する。

つまり、この条文は「CFCで日本側に合算された所得があるなら、その所得に対応する現地税額については、親会社自身が払った外国法人税と同じものとして扱ってよい」と言っています。

このため、×1年にCFC合算が立たないなら、×1年の10万円は66条の7第1項の入り口に乗りません。反対に、×2年に正のCFC合算額が立つなら、×2年の14万円はその範囲でFTC候補になります。

4. 66条の7はそこで終わらず、みなし外税額を益金算入させます

租税特別措置法66条の7第2項

第1項で控除対象外国法人税とみなされた金額は、政令で定める事業年度の所得金額計算上、益金の額に算入する。

租税特別措置法施行令39条の18第12項・第13項

CFC合算により益金算入された金額と、66条の7第1項でみなし外税となった金額は、いずれも法人税法69条の控除限度額計算における調整国外所得金額に含まれる。

このつながりまで見て初めて、「なぜCFC事案では国外所得金額ではなく調整国外所得金額で見るのか」が理解できます。66条の7第1項で外税に変え、66条の7第2項で益金に戻し、39条の18でその両方を控除限度額に反映させる、という一連の仕組みです。

設例に条文を当てはめる

設例では、条文の流れに従うと次の順に考えます。まず×1年に66条の6による正の合算額が出るかを見て、出ないなら×1年の10万円は66条の7第1項に入りません。次に×2年で正の合算額が出れば、その年の14万円がFTC候補になり、さらに66条の7第2項と39条の18により、合算額と14万円の両方が調整国外所得金額側に入ります。

そのうえで、数値が分かれるのは「▲100万円」「300万円」が39条の15のどの段階の数字かが不明だからです。

読み方 意味 結論の動き
パターンA 提示額は、現地帳簿ベースないし税引後ベースの概算値であり、39条の15第1項・第2項の基準所得金額計算をまだ経ていない 前期税額10万円は前期欠損を90万円に圧縮し、翌期合算額を押し上げる方向で読む
パターンB 提示額は、すでにCFC計算上の基準所得金額に近い値である ×2年では39条の15第5項に従い、100万円の欠損と14万円の当期税額をそのまま控除する方向で読む

実務では、現地申告書、試算表、税効果仕訳、納税計算書を見て、提示値がどの段階の数字かを確定する必要があります。

パターンA: 条文の二段階構造を前提に読む場合

この読み方では、39条の15の基準所得金額計算と適用対象金額計算を通してみるため、×1年の10万円は前期欠損金額を90万円に圧縮する方向に効き、×2年の14万円は当期適用対象金額の中では相殺される方向になります。

×1年 欠損金額 ≒ 100万円 − 10万円 = 90万円 +×2年 適用対象金額 ≒ 300万円 − 90万円 = 210万円 +×2年 みなし外税額 = 14万円（100%保有前提） +控除限度額計算に入る調整国外所得金額のベース ≒ 210万円 + 14万円 = 224万円

この読み方では、条文全体のつながりはこうなります。×1年は66条の6で正の合算額が出ないため、10万円は66条の7第1項に入りません。しかし、その10万円は39条の15の欠損金額計算に影響し、翌年の66条の6の合算額を押し上げます。そこで初めて、×2年の14万円が66条の7第1項でFTC候補になり、66条の7第2項と39条の18で調整国外所得金額側にも反映されます。

パターンB: 提示額をすでに基準所得金額に近い数値とみる場合

この読み方では、提示の300万円をすでに39条の15第1項・第2項後の数字とみるため、×2年は39条の15第5項の文言どおりに、100万円の欠損と14万円の当期税額をそのまま控除する整理になります。

×1年 欠損金額 = 100万円 +×2年 適用対象金額 = 300万円 − 100万円 − 14万円 = 186万円 +×2年 みなし外税額 = 14万円（100%保有前提） +控除限度額計算に入る調整国外所得金額のベース = 186万円 + 14万円 = 200万円

この場合でも条文の骨格自体は同じです。×1年は66条の7に入らず、×2年だけが66条の7第1項の入り口に乗る。ただし、66条の6の前提となる39条の15の読み方を簡略化しているので、合算額が186万円、調整国外所得金額側が200万円という整理になります。

どちらが実務上有力か

条文を一体で読むなら、パターンAの方が自然です。理由は、39条の15が「基準所得金額を先に作り、その後で欠損金額と当期法人所得税を控除する」という二段階構造だからです。

ただし、ユーザー提示値が何を指す数字かが明示されていない以上、申告・修正申告では、現地帳簿から39条の15第1項又は第2項に沿って基準所得金額を再計算するのが安全です。

このケースで確定してよい最低限の結論

どのパターンでも共通するのは次の2点です。

1. ×1年の10万円は、その年単独ではFTCにならない。

2. ×2年の14万円は、CFC合算が立てば66条の7第1項によりFTC候補になる。

控除限度額との接続

法人税法施行令142条1項・3項 抜粋

控除限度額は「法人税額 ×（調整国外所得金額 ÷ 所得金額）」で計算する。もっとも、調整国外所得金額は所得金額の90%相当額を上限とする。

したがって、最終的な当期外国税額控除額は、14万円がそのまま落ちるとは限らず、

当期外国税額控除額 = min( 14万円, 控除限度額 )

で決まります。ただし、今回の設例はシンガポール税額が14万円と小さいため、日本側で十分な所得と法人税額があれば、通常は14万円全額が当期控除に収まる可能性が高いです。

正確な控除限度額を出すには、日本親会社の当期所得金額、他の税額控除、地方法人税・住民税の情報が必要です。

実務で確認すべき点

  • シンガポール子会社の持株割合が100%か。100%でないなら、課税対象金額もみなし外税額も持分按分になる。
  • ×1年の10万円、×2年の14万円が、39条の15第5項2号の「法人所得税」に当たる税か。
  • 提示の「所得」が、現地帳簿利益・現地税務所得・CFC基準所得金額のどれか。
  • ×1年と×2年で、39条の15第1項（本邦法令基準）か第2項（本店所在地国法令基準）かの選択が同じか。
  • 配当調整、控除対象配当等、部分合算論点がないか。
  • 修正申告時に、66条の7関係明細、別表六、別表十七（三の二）等の整合を取り直しているか。
