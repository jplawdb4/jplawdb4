1. ゴム製品製造業で問題となる典型的な無形資産の類型

ゴム製品製造業では、以下の無形資産が移転価格上の論点となりうる。特に親会社が長年にわたり蓄積した製造技術・ノウハウを海外子会社に提供している場合、これらが「独立企業間価格で対価を伴うべき無形資産」に該当するかが核心的論点となる。

無形資産の類型具体例（ゴム製品）移転価格上の位置づけ
製造技術・特許加硫技術、押出成形技術、射出成形技術に関する特許権・実用新案権法的保護のある無形資産。ライセンス取引として独立企業間価格の算定対象
配合ノウハウゴム配合処方（コンパウンド設計）、加硫促進剤の配合比率、老化防止剤の選定、充填剤の混合比営業秘密として法的保護なくとも、超過収益の源泉であれば無形資産に該当
品質管理手法検査基準、不良率管理ノウハウ、工程管理（SPC）手法、品質保証プロセス製品の競争力に直結。機能・リスク分析において重要な考慮要素
金型設計技術金型設計ノウハウ、金型図面（CADデータ）、金型メンテナンス技術図面・設計データの移転はノウハウ供与。金型そのものの移転は有形資産取引
製造プロセス生産ライン設計、工程フロー、設備レイアウト、省エネ・歩留まり改善技術秘密工程（secret process）としてロイヤリティの対象
ブランド・商標親会社ブランド名での販売、OEM先からの信用マーケティング無形資産として独立した対価設定が必要な場合あり
顧客リスト・取引網OEM供給先との関係、自動車メーカーとの取引実績事務運営指針2-11で「取引先等のネットワーク」として例示
実務上のポイント: ゴム製品は配合処方が品質・性能を決定的に左右するため、配合ノウハウは特許権に比肩する価値を持つことが多い。これが無償で提供されている場合、税務当局はみなしロイヤリティの認定を検討する可能性がある。
出典: 国税庁税務大学校「移転価格課税における無形資産の使用により生じた利益の帰属及びその配分」 / 押方移転価格会計事務所「無形資産は移転価格税制の最重要検討項目」 / 中央国際会計事務所「移転価格税制の無形資産とは？」

2. 日本の移転価格事務運営指針における「無形資産」の定義と範囲

2.1 法令上の定義

租税特別措置法第66条の4第2項第3号ハに基づき、無形資産は以下のように規定されている。

  • 特許権、実用新案権、意匠権、商標権等の産業財産権
  • 著作権
  • 営業秘密（不正競争防止法第2条第6項に規定するもの）
  • 上記に準ずるもので、その譲渡・貸付けが独立の事業者の間で通常の取引条件に従って行われるとした場合に対価が支払われるべきもの

2.2 2022年改正のポイント

2022年6月10日、国税庁は移転価格事務運営要領を改正した。主な改正点は以下のとおり。

  • 金融取引に関する規定の整備: グループ内貸付・債務保証・キャッシュプーリング等
  • 費用分担契約（CCA）に関する規定の整備
  • 参考事例集の改訂: 関連者間貸付取引（事例4）、債務保証取引（事例4）、キャッシュプーリング（事例7）の追加・改訂

2.3 無形資産の広範な捉え方

事務運営指針2-11は、調査において検討すべき無形資産として以下を包括的に列挙している。

  • 技術革新を要因として形成される特許権、営業秘密等
  • 従業員等が企業活動を通じて形成したノウハウ（経営、営業、生産、研究開発、販売促進活動等）
  • 生産工程、取引先等のネットワーク
重要: 法的保護の有無にかかわらず、「重要な価値を有し、収入の源泉となっている資産」であれば広く無形資産として認識される。ゴム製品の配合ノウハウや品質管理手法は、特許登録されていなくとも無形資産に該当しうる。
出典: 国税庁「移転価格事務運営要領 第3章 調査」 / PwC Japan「移転価格事務運営要領の一部改正について（2022年）」 / 国税庁「移転価格事務運営要領の制定について」

3. 事務運営指針の無形資産取引に関する主要規定（2-9〜2-13）

条項見出し主要内容
2-9 無形資産取引に係る独立企業間価格の算定 棚卸資産の売買取引と無形資産のライセンス取引が別個に行われている場合、それぞれの取引ごとに独立企業間価格を算定する。棚卸資産の価格にロイヤリティが含まれている場合はその点を考慮。
2-10 比較対象取引の選定 無形資産取引の比較対象取引を選定する際、無形資産の種類、対象範囲、使用態様等の類似性を検討。完全な比較対象取引が存在しない場合の差異調整の方法。
2-11 調査において検討すべき無形資産 無形資産が法人又は国外関連者の所得にいかに貢献しているかを検討する際、重要な価値を有し収入の源泉となっている資産を包括的に考慮する。特許権、営業秘密、ノウハウ、生産工程、取引先ネットワーク等を例示。
2-12 無形資産の形成・維持・発展への貢献 法人と国外関連者のそれぞれが無形資産の形成、維持又は発展にどの程度貢献しているかを評価する。研究開発活動、品質向上活動、市場開拓活動等の貢献度を考慮。（OECD DEMPEフレームワークに対応）
2-13 無形資産の使用許諾取引（みなしライセンス） 法人又は国外関連者が、相手方の所有する無形資産を使用許諾契約なく使用している場合、無形資産の使用許諾取引があるものとして独立企業間価格を算定する（無形資産の譲渡と認められる場合を除く）。使用許諾取引の開始時期は、非関連者間取引の事例を参考に適切に決定する。
本件への示唆（2-13が最重要）: 日本親会社がタイ子会社に製造技術・配合ノウハウを提供しているにもかかわらず、ロイヤリティ契約を締結していない場合、事務運営指針2-13に基づき、使用許諾取引が存在するものとみなして独立企業間価格（みなしロイヤリティ）が算定される。これは契約の有無にかかわらず適用される点が極めて重要。
出典: 国税庁「移転価格事務運営要領 第3章 調査」 / 日本法令外国語訳DBシステム「移転価格事務運営要領」 / 国税庁「移転価格税制の適用に当たっての参考事例集」

4. OECD移転価格ガイドライン第6章・DEMPEフレームワーク

4.1 DEMPEとは

OECD移転価格ガイドライン第6章（2015年BEPS行動計画8-10の成果として策定、2022年版に統合）は、無形資産からの利益配分を決定するためのDEMPEフレームワークを導入した。

要素英語内容ゴム製品での具体例
DDevelopment（開発）無形資産の初期創出活動新配合処方のR&D、新製法の開発、特許出願
EEnhancement（改良）既存無形資産の価値向上配合改良、歩留まり改善、耐久性向上研究
MMaintenance（維持）無形資産の機能維持活動品質管理体制の運用、製造工程の管理
PProtection（保護）法的権利の保護活動特許管理、営業秘密管理（秘密保持契約等）
EExploitation（活用）無形資産の商業化・収益化技術を使った製品の製造販売、ライセンス供与

4.2 法的所有 vs 経済的所有

OECD BEPSプロジェクト以降、法的所有のみでは無形資産からの利益帰属の根拠にならないことが明確化された。無形資産からのリターンを得るためには、DEMPE機能を実際に遂行し、関連するリスクを管理する「実体（substance）」が必要とされる。

  4. 実際の取引条件と各当事者の行動の確認

5.2 日タイ租税条約第12条のロイヤリティの定義

「著作権、特許権、商標権、意匠、模型、図面、秘密方式若しくは秘密工程の使用若しくは使用の権利の対価として、又は産業上、商業上若しくは学術上の経験に関する情報の対価として受領するすべての種類の支払金」

実務上の注意:
  • ゴム配合ノウハウの提供は「秘密工程」又は「産業上の経験に関する情報」に該当し、ロイヤリティとして源泉税の対象となる
  • タイ歳入局は、技術支援契約（Technical Service Agreement）であっても、その内容が専門的知見の供与に該当する場合、ロイヤリティとして課税権を行使する傾向がある
  • タイ子会社が源泉徴収した税額は、日本親会社側で外国税額控除の対象となる
  • タイにおいてロイヤリティの支払いを損金算入するためには、支払先が適切な対価であることの立証が必要

7. ロイヤリティを支払っていない場合のリスク

7.1 日本側のリスク

リスク類型内容根拠条文
移転価格課税（みなしロイヤリティ） 事務運営指針2-13に基づき、使用許諾契約がなくとも、無形資産の使用許諾取引が存在するものとみなして独立企業間価格を算定。遡及的にロイヤリティ収入を認定し、所得加算される。 租特法66条の4 / 事務運営指針2-13
国外関連者寄附金認定 無形資産を無償で提供していた場合、その経済的価値に相当する金額が国外関連者への寄附金として認定される可能性。全額損金不算入。 法人税法37条 / 租特法66条の4第3項
延滞税・加算税 移転価格更正に伴い、過少申告加算税（10〜15%）、延滞税が賦課される。仮装隠蔽があれば重加算税（35〜40%）。 国税通則法65条等
二重課税 日本で所得加算されても、タイ側で対応的調整（corresponding adjustment）が自動的には行われない。相互協議（MAP）を申請する必要あり。 日タイ租税条約第25条

7.2 タイ側のリスク

  • 損金算入の否認: ロイヤリティの遡及的支払いについて、タイ歳入局がその合理性・相当性を否認し、損金算入を認めない可能性
  • 源泉税の追徴: ロイヤリティとして支払うべきであった金額に対する源泉税（15%）の追徴
  • 移転価格調査: タイも2002年にOECD移転価格ガイドラインに準拠した通達を導入しており、タイ側からの独自の移転価格調査リスクも存在

7.4 推奨される対応策

  1. 無形資産の棚卸: 親会社からタイ子会社に提供されている無形資産を網羅的に洗い出す
  2. DEMPE分析の実施: 各無形資産について、親会社・子会社それぞれのDEMPE機能を分析
  3. ロイヤリティ契約の締結: 無形資産の提供に対して適切な対価を設定した技術ライセンス契約を締結
  4. 料率の合理性の文書化: 比較対象取引の調査又はコストアプローチ等により料率の妥当性を立証する移転価格文書（ローカルファイル）を作成
  5. 棚卸取引価格との整合性確認: 棚卸資産の売買価格にロイヤリティ相当額が含まれていないかを確認（二重課税回避）
  6. APAの検討: リスクが高い場合、事前確認（APA: Advance Pricing Arrangement）の申請を検討
最大のリスクシナリオ: 日本の税務当局が事務運営指針2-13に基づきみなしロイヤリティを認定し、過去数年分の所得を加算更正。タイ側では対応的調整が行われず、同一の所得に対して日泰双方で課税される「経済的二重課税」が発生する。相互協議による解消には長期間を要するため、予防的な対策が不可欠。

項目結論
無形資産の該当性ゴム配合ノウハウ・製造技術・品質管理手法は、特許登録の有無にかかわらず、移転価格税制上の無形資産に該当する可能性が高い
事務運営指針の適用2-13により、使用許諾契約がなくとも、みなしライセンス取引として独立企業間価格が算定される
タイの源泉税国内法・条約とも15%。ロイヤリティの定義は広く、技術ノウハウの提供は該当する
料率の目安化学・ゴム分野で売上高の2〜5%（配合ノウハウ＋製造プロセスの包括ライセンスで3〜5%が目安）
DEMPE分析親会社がDEMPEの大部分を担っている場合、適切なロイヤリティ収入が親会社に帰属すべき
最大リスクみなしロイヤリティ認定による遡及的所得加算＋経済的二重課税の発生
推奨対応技術ライセンス契約の早期締結＋移転価格文書の整備＋必要に応じてAPA申請
