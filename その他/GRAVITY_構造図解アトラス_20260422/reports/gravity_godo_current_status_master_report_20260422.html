1. 本レポートの結論

現時点で最も重要な結論は、Gravity合同会社 を単体のGKとして見るだけでは、この案件の本質を見誤るという点にあります。公開資料を積み上げると、これは単純な一層構造ではなく、platform / strategy、domestic LPS、foreign sleeve、domestic GK/TK operator、TMK / 信託受益権、real assets の各層が重なった多層ストラクチャーです。

その中で Gravity合同会社 は、TK 層では営業者であり、下流 TMK 層では 特定出資 と 優先出資 の引受人として機能する、日本側の中心的な GK/SPC です。法的に見ると、上の箱では事業者、下の箱では投資家、という二重の役割を持つ箱だと理解するのが自然です。

また、上流レイヤーでは JIF Japan Partners LP が Tokumei Kumiai Operator 経由で日本物流不動産へ投資する foreign sleeve として最も強く見えており、そのさらに上流には Japan DH4 投資事業有限責任組合 が乗る、というのが現時点の best explanation です。他方、Japan Income Fund合同会社 / ジャパンインカムファンド投資事業有限責任組合 は重要な国内ハブですが、Gravity合同会社 の利益分配の直後受領者というより、日本側LPSハブまたは parallel route として見る方が整合的です。

下流側では、現時点の strongest direct-name candidate は Gravity特定目的会社 です。これに加えて、GLP Japan DH4特定目的会社 と GLP DH4 Exc特定目的会社 が parallel / additional candidate family として残っています。ただし、Gravity合同会社 -> Gravity特定目的会社、あるいは Gravity合同会社 -> DH4名義TMK群 の direct evidence はまだ未取得であり、ここは最重要の未解決点です。

さらに税務面では、Gravity合同会社匿名組合 の利益分配は国内法上まず 所得税法161条1項16号 の国内源泉所得と読むのが自然で、支払先が非居住者・外国法人側であるなら、実務の安全側初期値は 20.42% 源泉です。条約軽減の可能性はありますが、JIF LP が pass-through なら恩典主体は JIF LP そのものではなく、その所得を取得したと扱われる構成員ごとに分かれるのが基本です。つまり、foreign LP が一枚挟まっているから自動的に treaty relief とは読めません。

3. Gravity合同会社について現時点で確定していること

Gravity合同会社 について、公開資料上かなり堅く言える部分は次のとおりです。第一に、Gravity AH合同会社 とは別法人です。これは似た名称のため混同しやすいのですが、投資導線も下流資産の持ち方も別です。Gravity合同会社 は TMK の特定出資・優先出資引受型、Gravity AH合同会社 は信託受益権取得型です。

第二に、Gravity合同会社 は金融庁 tokurei/011.pdf 上の届出者であり、Gravity合同会社匿名組合 の届出主体です。代表社員は Gravity一般社団法人、2025年9月30日現在の職務執行者は 川島聖、所在地は 東京都中央区八重洲二丁目2番1号 です。gBizINFO 上の法人番号は 4010403022859 で整合します。

第三に、tokurei/012.pdf 上、Gravity合同会社匿名組合 の投資内容は、匿名組合出資をもって特定目的会社の発行する特定出資及び優先出資を引受けることにより、間接的に不動産等へ投資 と整理されています。したがって、Gravity合同会社 は匿名組合の営業者として上から資金を受け、それを使って TMK の証券を引き受ける構造を示唆します。

第四に、tokurei/012.pdf 上で見える投資家属性は、外国法人又は外国人等(1)、非QII 投資家ゼロです。この一点だけでも、Gravity合同会社匿名組合 における匿名組合員側は single foreign-type investor と読むのが自然になります。ここが後で JIF LP を最有力候補とみる足場になります。

5. 上流レイヤーの主体別整理

5.1 Ares / GLP / 日本GLP

最上流 platform としては、Ares による GLP 関連プラットフォームの取り込みと、その下にある日本GLPの運用レイヤーを押さえる必要があります。Ares 2025年の SEC Exhibit 21.1 では、JIF Japan Partners GP, Pte. Ltd.、Japan Income Fund GK、GLP Japan 関連主体が同一重要子会社群に並んでおり、これにより JIF / Japan Income Fund / GLP Japan がバラバラではなく、一つの platform family に属することが裏打ちされます。

また GLP 公式ページでは、GLP Japan Income Fund が open-end / core 型の日本物流 income strategy として位置づけられ、2020年開始・その後の拡大が説明されています。ここから分かるのは、GRAVITY案件が単発案件だけでなく、広い JIF strategy 文脈のなかで読むべきだということです。

5.2 Japan DH4 投資事業有限責任組合

Japan DH4 投資事業有限責任組合 は、今回の全体構造を読むうえで重要な国内LPSです。tokurei_012 上で、この主体は 海外リミテッドパートナーシップに対する出資を通じて、間接的に不動産等に対する投資を行う と記載されています。これは、国内LPSから foreign LP に上がるルートを公式資料が直接示している、という意味で極めて重要です。

この文言があるため、JIF Japan Partners LP の直上候補としては、Japan DH4 が非常に強い位置に立ちます。少なくとも current best view では、Japan DH4 -> JIF Japan Partners LP は direct proof ではないが、高確度推定として扱ってよいと考えられます。

5.3 JIF Japan Partners LP

JIF Japan Partners LP は、今回の GRAVITY 局面で最重要の foreign sleeve です。金融庁 tokurei_012 では、portfolio of cash-yielding logistics facilities in Japan に対し、Tokumei Kumiai investment in Tokumei Kumiai Operator を通じて間接投資すると明示されています。これは、単独案件より portfolio-level stabilized logistics facilities への投資戦略を示唆します。

また、GP として JIF Japan Partners GP, Pte. Ltd. が確認され、シンガポール所在の GP と LP の組合せが見えています。もっとも、ここで注意すべきは、QII 01_b は周辺行の括弧書きを誤読しやすく、JIF GP -> JIF LP の対応確認は tokurei_012 を優先すべきだという点です。

いずれにせよ、現時点の公開資料では、JIF Japan Partners LP が Tokumei Kumiai Operator に対する投資を通じて日本物流資産へ間接投資する foreign LP であることはかなり堅いです。

5.4 Japan Income Fund合同会社 / ジャパンインカムファンド投資事業有限責任組合

Japan Income Fund合同会社 と ジャパンインカムファンド投資事業有限責任組合 は、GRAVITY案件を読むときに非常に重要ですが、位置づけを誤ると全体が崩れます。これらは公開資料上、匿名組合の営業者に対する匿名組合出資 を行う国内LPSハブとして現れており、しかも国内の金融機関・事業法人など多数の投資家層を伴います。

したがって、これを Gravity合同会社 の匿名組合利益分配の直後受領者とみるより、日本側の broad investor aggregation layer として見る方が自然です。つまり、上流の domestic LPS の一つではあるが、JIF LP や Gravity と同じ文脈で直列に並ぶとは限らない、ということです。

6. 下流レイヤーの主体別整理

6.1 Gravity合同会社

Gravity合同会社 は、上から見れば匿名組合の営業者、下から見れば TMK 証券の引受人です。この二面性は一見矛盾しているように見えますが、契約関係が違うだけで法的には整合します。すなわち、TK 契約との関係では営業者、TMK との関係では投資家 です。

経済的にいえば、Gravity合同会社 は上流の投資家資金を一度受け止め、それを TMK 証券へ変換して下流資産へ流す装置です。この意味で、GRAVITY案件の中心的な relay box と言えます。

6.2 Gravity AH合同会社

Gravity AH合同会社 はしばしば Gravity合同会社 と混同されますが、投資導線が違います。Gravity AH合同会社匿名組合 は、匿名組合出資をもって不動産信託受益権を取得する 型として理解されます。JCR の資料では、Ares 系日本GLPが運用する大型物流ファンドの保有・資金調達ビークルとしての位置づけがかなり強く示されています。

したがって、Gravity AH は GRAVITY family の重要な sibling ですが、TMK の特定出資・優先出資を引き受ける Gravity合同会社 とは、下流資産の持ち方が違う別箱として扱う必要があります。

6.3 JDP3 / JDP4 / Sakai ルート

初期段階では、JDP3、JDP4、Sakai も JIF の直接下流候補に見えました。しかし、追加 official source によって、これらはむしろ 案件固有スリーブ 又は project cluster として理解する方が自然になりました。

JDP3 は国土交通省資料で GLP ALFALINK 茨木1 の提案者側として現れ、個別新築開発案件色が強いです。JDP4 は大阪市の建築・入札資料から複数の土地・建築案件を束ねる cluster と読めます。Sakai は Hon Hai report で associate として現れ、単独案件または JV 色が強いです。

このため、JDP3 / JDP4 / Sakai を JIF の直接下流候補として主線に置くより、比較例として保持しながら、portfolio-level operator の主線は Gravity合同会社 に寄せる、というのが current best view です。

7. Gravity特定目的会社とDH4名義TMK群の位置づけ

下流 TMK を読む段階で、現在もっとも面白いのは Gravity特定目的会社 が前面に出てきたことです。金融庁の current 特定目的会社届出一覧 に、Ｇｒａｖｉｔｙ特定目的会社 が現存し、しかも Gravity合同会社 と名称・住所・電話番号帯が揃っています。さらに QII 01_b でも、Ｇｒａｖｉｔｙ合同会社 と Ｇｒａｖｉｔｙ特定目的会社 の双方が同じ official list に現れます。

加えて、GLP J-REIT の 2021-05-27 開示では GLP 狭山日高Ⅱ の取得文脈に 狭山日高2ロジスティック特定目的会社 が現れ、二次ソースでは 狭山日高2ロジスティック特定目的会社 -> Gravity特定目的会社 の改称痕跡が確認されています。この official-to-secondary bridge により、Gravity特定目的会社 = GLP 狭山日高Ⅱ 系統の current-name TMK という読みが一段強くなりました。

他方で、GLP Japan DH4特定目的会社 と GLP DH4 Exc特定目的会社 も current official list に現存しています。これらについては、旧名称 舞洲1ロジスティック特定目的会社 と 柏2ロジスティック特定目的会社 からの rename trace があり、それぞれ GLP 舞洲Ⅰ、GLP 柏Ⅱ の asset-level TMK だったことが official disclosure と整合します。

そのため、下流 TMK frontier はもはや 名前不明 ではなく、Gravity特定目的会社 を strongest direct-name candidate としつつ、GLP Japan DH4特定目的会社 / GLP DH4 Exc特定目的会社 を parallel / additional candidate family として保持する段階に進んでいます。ただし、そのいずれとも Gravity合同会社 を直結する公開資料はまだ未取得です。

8. TK分配金について現時点で言えること

この論点は、法的に直後の受領者 と そのさらに上流の受益レイヤー を分けないと誤ります。まず商法上、匿名組合契約における利益分配の相手方は 匿名組合員 です。したがって、Gravity合同会社匿名組合 の利益分配の法的な直後受領者は、TMK でも日本GLPでもなく、匿名組合員側です。

そして tokurei_012 では、Gravity合同会社匿名組合 の投資家属性が 外国法人又は外国人等(1) と見えています。これは、公開届出の読みとしては、直後受領者が 単一の foreign-type investor であることを示唆します。ここに最も強く整合する実名候補が JIF Japan Partners LP です。理由は、この LP 自身が Tokumei Kumiai Operator への投資を明示しているからです。

そのさらに上流については、Japan DH4 が 海外リミテッドパートナーシップに対する出資 を明示しているため、Japan DH4 -> JIF Japan Partners LP -> Gravity合同会社匿名組合の匿名組合員 という layering が現時点で最も合理的です。逆に、Japan Income Fund合同会社 は日本側LPSハブとして重要ですが、直後受領者というより上流 / parallel の層として読む方が自然です。

したがって、TK分配金についての current best reading は、次のようになります。

この整理の意味は大きく、Gravity合同会社 -> 日本GLP のように単純な企業グループ内送金で捉えるのではなく、TK契約上の利益分配 -> foreign LP -> さらに上流のLPS/投資家 というファンドレイヤーで読む必要がある、ということです。

9. 日本の源泉税論点

税務面の出発点はかなりクリアです。Gravity合同会社匿名組合 の利益分配は、国内法上まず 所得税法161条1項16号 の 匿名組合契約に基づく利益の分配 として国内源泉所得に入ります。国税庁 No.2878 も同趣旨です。

そのため、直後受領者が非居住者又は外国法人側であるなら、所得税法212条1項 により Gravity合同会社 が源泉徴収義務者となり、No.2884 によれば税率の入口は 20.42% です。国外送金だから外れるという理屈は、212条2項 の存在から採れません。

実務上ここで誤りやすいのは、212条5項 をそのまま主軸に持ってくることです。しかし、今回の中心は 161条1項16号 であって、161条1項4号 の partnership allocation 類型とは条文上の足場が違います。したがって、少なくとも current issue の軸は 212条1項・2項 で押さえるのが自然です。

ここから導かれる実務の安全側初期値は、Gravity合同会社 -> JIF Japan Partners LP を仮置きしたとき、まず 20.42%源泉 を baseline に置く、というものです。これは「最終的に必ずその税率で終わる」という意味ではなく、条約軽減を立証できるまではその前提で動くのが最も保守的だ、という意味です。

10. JIF LP が pass-through なら誰が条約恩典を取るのか

この論点の本質は、JIF LP に自動的に treaty benefit が落ちるわけではない、という点です。もし JIF Japan Partners LP が fiscally transparent / pass-through entity と評価されるなら、日本の見方としては、その所得を居住地国法上取得したと扱われる者 が誰かを見にいきます。つまり、JIF LP の構成員ごと に恩典主体が割れる可能性が高い、ということです。

国税庁 No.2888 は、日本と相手国で entity の課税上の取扱いが異なる場合、届出書、付表、軽減対象構成員名簿 を前提に treaty relief を処理する建付けを示しています。ここからも、問題が LP という箱 で終わらず、誰に所得が帰属するか に下りていくことが分かります。

したがって、JIF LP が pass-through だと仮定した場合の回答は、単一ではありません。構成員の所在国、各国条約、各構成員への所得帰属割合、受益者性、PE の有無によって分かれます。つまり、誰が条約恩典を取るのか という問いの答えは、JIF LP ではなく、その中の誰が derive したかで決まる、が基本です。

ここでさらに重要なのは、透明体だからといって常に誰かが恩典を取れるわけではないことです。日米条約のように、匿名組合的 arrangement について、entity だけでなく参加者側の treaty benefit も否認し得る special denial がある条約もあります。このため、pass-through = 自動的に partner look-through で軽減 と考えるのは危険です。

11. シンガポール条約を視野に入れたときの含意

今回の JIF LP はシンガポール sleeve と強く疑われるため、日本・シンガポール協定が重要です。ただし、今回確認した synthesized text の範囲では、匿名組合を名指しする独立条項は見えていません。したがって、まずこの所得を 利子、配当、その他所得、事業利得 のどれとして処理するのかを決める必要があります。

国税庁論叢では、典型的匿名組合なら 利子、非典型又は PE 型なら 事業利得 が問題になると整理されています。Gravity 局面でどこに落ちるかは、JIF LP の関与の深さや契約実態を見ないと断定できません。

さらに、シンガポール条約には 22条2項 の exempt / substance 制限があります。すなわち、シンガポール側で実質課税がなく、かつ実体も実活動も乏しい場合、仮に形式的にはシンガポール vehicle でも軽減が止まる余地があります。したがって、Singapore LP だから treaty relief という短絡も危険です。

13. 実務上の含意

税務調査、税務DD、移転価格ではなくファンド構造・源泉税・条約論点を読む局面では、Gravity合同会社 を単なる SPC として片づけると危険です。むしろ、この箱は 上流資金の受皿 と 下流TMK投資 をつなぐ結節点であり、どのレイヤーで何を受け、何を払い、誰に帰属させるのかが核心です。

また、TK分配金については、法的に誰が直接受けるか と 経済的に誰が最終的に受益するか を切り分けないと、法人税・源泉税・条約恩典の議論が崩れます。ここで JIF LP と Japan DH4 を一枚岩にしたり、Japan Income Fund を直後受領者だと早合点したりすると、レイヤーが混ざります。

源泉税実務では、20.42%源泉 baseline を置いたうえで、軽減を崩すには entity classification と member-level treaty entitlement を立証する必要があります。したがって、今後の資料取得では、JIF LP の構成員名簿、居住者証明、条約届出ルート が最優先になります。

14. 今後の最重要 frontier

次に取るべき証拠は、かなりはっきりしています。

  • Gravity合同会社 -> Gravity特定目的会社 の direct evidence
  • JIF Japan Partners LP -> Gravity合同会社匿名組合 の direct evidence
  • Japan DH4 -> JIF Japan Partners LP の direct evidence
  • JIF LP の entity classification と member roster
  • 条約届出書・付表・構成員名簿ベースで軽減を立証できるかどうか

この5点が埋まると、GRAVITY案件は「合理的推定の束」から「かなり強い立証構造」へ一段進みます。
