OMORI MM ARE GLOBAL PTE. LTD. 現状研究レポート

本ページは、2026年4月23日時点で積み上げた公開情報ベースの調査成果を、`対象法人の特定`、`全体ストラクチャー`、`通常資金フロー`、`上流送金チャネル`、`未解明 frontier` の順に統合した現状版レポートです。結論を先に言えば、この法人は単独の営業会社というより、`Singapore vehicle + Japan mirror pair + SPC管理ハブ + selective transaction trace` から成る cross-border 不動産・投資ビークル群の一角として読む方が、現状では説明力が高いです。

現状サマリー

現時点で高い確度で言えるのは、対象は `OMORI MM ARE GLOBAL PTE. LTD. (UEN 202239636H)` であり、旧名は `SAKAI ARE GLOBAL INVESTORS PTE. LTD.`、公開ソース上の沿革では `23 Lim Tua Tow Road`、`1 Scotts Road #24-05`、`77 High Street #05-01` という住所断面と、`70201 management consultancy` から `68103 real estate letting` への activity change が見える、という点です。

ただし、これをそのまま `シンガポールの不動産営業会社` と読むのは自然ではありません。日本側には `Ｏｍｏｒｉ ＭＭ合同会社` と `一般社団法人Ｏｍｏｒｉ ＭＭ２` の mirror-like pair があり、比較対象となる `Ｅｓａｋａ ＡＲＥ Ｇｌｏｂａｌ合同会社 / 一般社団法人` には `適格機関投資家等特例業務届出者` と `J-REX` の取引痕跡が見えます。したがって、OMORI単体よりも `ARE GLOBAL vehicle cluster` の一部として読む方が筋が良い状態です。

シンガポール側の会社存在、旧社名、住所変遷、SSIC変遷、日本側 mirror pair、ESAKA 側の QII trace と J-REX trace。

Unresolved まだ未立証の核心

株主、UBO、nominee 構造、直結 ownership chain、実際の対象資産、Singapore からの関与形態。

全体ストラクチャー

現時点で最も説明力の高い全体像は、`6層構造` です。個社の足し算ではなく、`Singapore vehicle layer`、`Japan mirror layer`、`administration hub layer`、`transaction / regulatory trace layer`、`ARE GLOBAL cluster layer`、`ownership / control frontier` の順に積み上がると見ると、公開情報がきれいにつながります。

中心の backbone を `Singapore vehicle → Japan mirror pair → administration hub → transaction/regulatory trace → ARE GLOBAL cluster → unresolved ownership/control` として整理した図です。現状のベストリーディングは `cross-border real-estate / investment vehicle structure` ですが、ownership chain 自体はまだ未立証です。
Layer 1: Singapore Vehicle

`OMORI MM ARE GLOBAL PTE. LTD.`、`ESAKA ARE GLOBAL PTE. LTD.` など。managed address、薄い営業痕跡、案件別 naming pattern が特徴です。

Layer 2: Japan Mirror Pair

`GK + 一般社団法人` の組み合わせが `OMORI` 側と `ESAKA` 側の双方に見えます。SPCや受け皿構造と整合します。

Layer 3: Administration Hub

`マニエラ銀座ビル4階` と `淀屋橋総合会計内` は、SPC管理、GK-TK、バックオフィスと明示的に結び付く専門家住所です。

Layer 4: Transaction / Regulatory Trace

`ESAKA` 側では QII 特例業務届出者の表示と、`J-REX` major customer trace があり、単なる shell より一段厚い痕跡があります。

Layer 5: ARE GLOBAL Cluster

`NAKAMACHIDAI`、`HANEDA NINGYOCHO`、`IKEBUKURO`、`SHONAI` などの周辺法人群が、shared naming と 1 Scotts migration pattern を示します。

Layer 6: Ownership Frontier

未解明なのはここです。株主、UBO、nominee、実際の案件資産、sponsor-level structure は、なお official records 待ちです。

比較上、`OMORI side = structure-heavy / trace-light`、`ESAKA side = structure-heavy / trace-visible` です。そのため、ESAKA は OMORI を読むための comparison spine として機能しますが、ESAKA の公開痕跡を OMORI に機械的に転写してはいけません。

通常資金フロー

公開実務資料から最も自然なのは、`主たる資金箱は日本側の GK / SPC` である、という理解です。一般社団法人は通常 `倒産隔離 / 議決権保有 / 親法人` のレイヤーであり、管理住所は `経理・出納・決算・届出` のレイヤーです。主箱ではありません。

  1. 投資家、QII、金融機関が `GK / SPC` に資金を入れる。
  2. `GK / SPC` が信託受益権、不動産、開発資産の取得資金を支払う。
  3. 運用収益や売却代金は、まず `GK / SPC` に戻る。
  4. そこから借入返済、税金、AM等のフィー、投資家分配が出ていく。
  5. 案件終了時には残余分配と清算に進む。

`OMORI` 側の日本 mirror pair はすでに清算済みなので、案件完了後に受け皿が消える一般的な SPC の終わり方とも整合します。ただし、これは現時点では `整合的` と言えるにとどまり、個別契約まではまだ見えていません。

公開証拠の確度マップ

何が `fact` で、何が `high-likelihood inference` で、何が `unresolved` かを一枚で固定した図です。会社ノードではなく、`証拠の種類` と `その証拠が支える論点` を中心に組んでいます。

左に `evidence sources`、中央に `what they establish`、右に `what remains unresolved` を置いた evidence-driven な整理です。構造仮説はかなり強い一方、ownership と sponsor proof はなお空いています。

上流送金チャネル

日本側 GK に入った資金や利益が上流へ抜ける法的チャネルは、通常次の6本です。重要なのは、`Singapore layer がどの法的地位にいるか` が分からない限り、どのチャネルが実際に使われたかは断定できない、という点です。

1. 匿名組合分配

TK 出資者が営業者の利益分配を受けるルートです。商法上、出資財産は営業者側に入り、匿名組合員は経営主体ではありません。

2. 合同会社の利益配当

Singapore layer が GK の社員なら、利益配当や清算分配のチャネルが現れます。

3. 持分払戻し

終局局面では、持分払戻しや清算レッグが現れます。OMORI 側の閉鎖はこの文脈と整合し得ます。

4. 利子

Singapore layer が lender なら、shareholder loan や direct loan の利子・元本返済チャネルが候補になります。

5. フィー・使用料

AM fee、advisory fee、arrangement fee、license fee など。国内源泉所得該当性は性質判定が必要です。

6. 不動産賃料

Singapore layer が日本不動産のオーナー・貸主にいる場合には、不動産賃料チャネルも論点になります。

国内法ベースでは、非居住者・外国法人への `匿名組合分配`、`貸付金利子`、`不動産賃料`、`一定の使用料等` は、通常 `20.42%` の源泉徴収の初期値で検討されます。日星租税条約の layer もありますが、どの treaty bucket に乗るかは支払の法的性質次第です。

現状の最有力順は、`Singapore layer = TK investor`、次いで `lender`、その次に `GK member`、さらにその次に `fee recipient` です。ただし、これは公開ソースだけからの優先順位であって、証拠確定ではありません。

まだ取れていない決め手資料

構造仮説を `公開ソース段階の高蓋然性` から `ownership / control の立証` に引き上げるには、次の official / company-side documents が必要です。

  • ACRA Business Profile
  • ACRA Register of Members
  • ACRA People Profile
  • 日本側 4 主体の登記事項証明書
  • 適格機関投資家等特例業務の届出詳細
  • 匿名組合契約、金銭消費貸借契約、分配計算書
  • 売買契約書または信託受益権譲渡契約
  • 銀行口座入出金、海外送金記録、租税条約届出書

特に CFC や税務DDの観点では、`日本側支配の有無`、`Singapore layer の実際の法的位置付け`、`actual tax burden`、`management and control` が決定的です。

現時点の暫定結論

現状のベストリーディングは、`OMORI MM ARE GLOBAL PTE. LTD.` を単独の実業会社とみるより、`ARE GLOBAL` 命名の cross-border 不動産・投資ビークル群の一角としてみることです。

ただし、最重要の ownership layer はまだ空いています。したがって現時点の結論は、`構造はかなり見えたが、誰の器かはまだ official records 待ち` です。

このため、CFC や withholding の最終判定は、現段階では `条件付きの preliminary view` にとどまります。現在の公開レベルで強いのは、`構造仮説` と `通常資金フロー` の方です。
